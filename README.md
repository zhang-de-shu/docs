# LLM 工程知识库

> 一套面向工程师的大语言模型(LLM)与 Agent 实战文档集。覆盖从**底层架构原理 → 训练对齐 → 推理部署 → Agent 与评估 → 具体模型解读**的完整链路,侧重**机制(怎么做的、为什么这么做)** 而非特性罗列。
>
> ⚠️ 全库通用提示:不少结论来自厂商技术报告与近期 preprint,LLM 领域迭代极快,**请在你自己的场景/分布上验证后再落地**。

---

## 阅读路径建议

- **入门打地基**:`01-基础原理` → Transformer 架构 → 预训练原理 → 数据工程;
- **做微调/对齐**:`02-训练与对齐` 三篇按 SFT → Agentic-SFT → 偏好/RL 顺序读;
- **做应用/上线**:`03-推理与应用工程`(部署、RAG、Prompt)+ `04-Agent与评估`;
- **追前沿模型**:`05-模型技术原理` 看各家旗舰怎么落地上述原理。

## 文档风格约定

本库所有技术文档遵循统一结构,便于快速定位:

- **第 0 节全景**:用"矛盾 → 解法"表格点出核心张力;
- **机制优先**:用 `>` 引用块解释"为什么这么做",而非罗列特性;
- **坑速查表**:每篇末尾有"常见坑汇总";
- **端到端流程**:给出可照做的实操步骤;
- **一句话总结 + 参考来源**:结论 + 可点击的原始出处链接。
