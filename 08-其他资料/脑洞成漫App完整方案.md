## 一、产品概述

### 1.1 产品定位

「脑洞成漫」是一个**一句话进、一张漫出**的 AI 条漫生成器：

- **极简输入**：用户只需要打一段话——今天遇到的倒霉事、一个荒诞的脑洞、想怼老板又不敢说的话、昨晚的梦。
- **完整输出**：App 自动完成「段子加工 → 分镜 → 逐格绘图 → 对白排版 → 合成条漫」全流程，产出一张风格统一、可直接发朋友圈/小红书的连环图。
- **风格锚点**：逗比 + 简笔线条。对标大众最熟悉的网络简笔漫画气质（参考：线条小狗、小蓝和他的朋友、小林漫画、暴走漫画的简笔感），而不是精致日漫——**越糙越有梗，越丑越好笑**。

### 1.2 为什么是现在

1. **图像模型能力拐点**：2025 年起，GPT Image / Gemini（Nano Banana）/ 即梦 Seedream 等模型已支持多图参考生成，角色一致性问题从"不可用"变成"工程可解"。
2. **简笔线条风格恰好是 AI 的甜区**：精致画风下 AI 的瑕疵（手部、透视）很扎眼；而逗比简笔风天然容忍变形，"画崩了"本身就是笑点。
3. **社交货币需求旺盛**：朋友圈/小红书的表达正在从"发照片"转向"发梗图"。用户想要个性化、与自己经历相关的梗图，但 99% 的人不会画画。

### 1.3 价值主张

| 用户痛点 | 我们的回答 |
|---|---|
| 有梗想表达，但不会画画 | 打字就行，AI 代笔 |
| 通用梗图人人都在用，没个性 | 每张漫都是"你自己的故事"，全网独一份 |
| 找模板工具拼梗图太麻烦 | 一句话全自动，30 秒出图 |
| AI 画图提示词写不来 | 用户全程不接触提示词，零学习成本 |

### 1.4 候选产品名（供讨论）

| 名字 | 气质 | 备注 |
|---|---|---|
| **脑洞成漫** | 直白、功能即名字 | 推荐主名，搜索友好 |
| 画个梗 | 口语化、动作感 | 适合小程序 |
| 逗漫 | 短、好记 | 需查商标 |
| 想法连环画 | 复古反差萌 | 备选 |
| 梗漫工厂 | 工具感强 | 备选 |

## 二、市场与竞品分析

### 2.1 竞品扫描

| 竞品类型 | 代表 | 优势 | 我们的差异点 |
|---|---|---|---|
| 通用 AI 绘画 | Midjourney、即梦、可灵 | 画质强、生态大 | 它们是"画一张图"；我们是"讲一个故事"，用户不用写提示词 |
| AI 漫画工具 | AI Comic Factory、Dashtoon、Pixton AI | 有分镜概念 | 多为美漫/日漫风，中文梗感弱；我们深耕中文语境逗比风 |
| 梗图模板工具 | 表情锅、各种梗图生成器 | 快、免费 | 只能用现成模板；我们从用户原创想法出发 |
| 小红书条漫博主 | 手工创作的条漫账号 | 内容有灵魂 | 他们产能低（一天一更）；我们把这种表达 democratize |
| 微信表情包平台 | 微信表情开放平台 | 分发渠道成熟 | 我们做的是"个人故事漫"，不是通用表情 |

### 2.2 竞争壁垒判断

- **短期没有壁垒**：纯 API 套壳很容易被抄。
- **中期壁垒三件套**：
  1. **风格资产**：自训的线条风格 LoRA / 专属画风模板，形成一眼可辨的品牌视觉；
  2. **梗能力**：段子生成模型的 prompt 体系 + 高质量梗数据积累，决定"好不好笑"，这是最难抄的；
  3. **用户角色资产**：用户训练/沉淀了自己的专属角色后，迁移成本极高（见 5.5）。

**结论**：这不是技术壁垒生意，是「风格 + 梗库 + 用户资产」的运营壁垒生意。早期拼速度和内容营销。

## 三、目标用户与核心场景

### 3.1 目标用户

| 用户群 | 画像 | 典型诉求 |
|---|---|---|
| 互联网打工人（核心） | 22-35 岁，重度社交媒体用户 | 吐槽上班、吐槽甲方/老板，发朋友圈 |
| 学生党 | 大学生为主，梗文化原住民 | 记录校园沙雕日常、玩梗 |
| 宝妈/生活记录者 | 25-40 岁 | 记录孩子的童言童语、家庭趣事 |
| 自媒体创作者 | 小红书/公众号博主 | 快速产出条漫配图，降低创作成本 |

### 3.2 核心使用场景

| 场景 | 输入示例 | 期待输出 |
|---|---|---|
| **日常吐槽** | "今天开会我提了个方案，老板说很好，然后原封不动变成了他的想法" | 4 格讽刺漫，最后一格打工人流泪竖大拇指 |
| **记录沙雕瞬间** | "我家猫把我杯子推下桌，然后低头看了一眼，表情毫无悔意" | 猫主角 4 格漫，最后一格特写猫的死鱼眼 |
| **脑洞具象化** | "如果蚊子会说话，吸你血之前还会说谢谢" | 6 格荒诞漫 |
| **情绪表达** | "周一的我 vs 周五的我" | 对比式 4 格 |
| **送礼/整活** | "给我兄弟画个漫画祝他 30 岁生日快乐，调侃他秃了" | 定制角色 + 祝福彩蛋格 |

### 3.3 关键设计原则

1. **全程零提示词**：用户只说人话，"提示词工程"全部由系统内化。
2. **30 秒出图**：超过 1 分钟用户流失率陡增，宁可降画质也要保速度（提供"高清慢速"选项兜底）。
3. **好笑 > 好看**：评估产出的第一标准是"梗有没有立住"，其次才是画面。
4. **可干预但不强制**：高级用户可改分镜、改对白、重绘单格；普通用户一键出图。

## 四、核心用户旅程

```
输入想法 ──► AI 段子化 ──► 分镜预览 ──► 逐格生成 ──► 合成条漫 ──► 分享/保存
   │              │             │             │            │
   │              ▼             ▼             ▼            ▼
   │         （可选）        （可选）      （自动）     编辑对白
   │         用户确认梗     微调某格      后台并行     换风格
   └──── 历史草稿箱 ◄──────────────────── 重新生成 ◄──┘
```

**关键体验节点**：

1. **等待体验**：生成约需 20-40 秒，必须用"进度梗"填充——把分阶段进度做成段子文案（"正在给你的老板画地中海…" "正在安排最后一格的神转折…"），把等待本身变成体验的一部分。
2. **首格预览**：第 1 格生成完立即展示，用户觉得风格/角色不对劲可以**立刻中止重来**，节省成本也节省时间。
3. **不满意出口**：每一格都支持"单独重绘"和"改这句话再画"，避免一张不满意就整组报废。

### 5.3 输入规范

- 文字输入：5~500 字；过短（<5 字）时引导补充或使用"帮我扩写"。

- 随机灵感：内置每日更新的脑洞题库，解决"不知道写什么"的冷启动问题。

### 5.4 输出规范

- 默认输出：竖版条漫（1080×自适应宽），适配朋友圈/小红书比例。

- 会员：无水印、高清导出、横版/方形/1:1 多比例。
- 附带文案：自动生成一段配图文案 + hashtag（如 #上班吐槽 #AI漫画），方便直接发小红书。

### 5.5 专属角色（留存核心设计）

**"养一只属于你的漫画小人"**：

1. 首次生成后，系统把主角形象沉淀为"我的角色"；
2. 之后每次生成默认沿用该角色（秃头打工人、自家猫、自己 Q 版形象…）；
3. V1.1 支持上传照片训练专属角色（3-5 张图，后台 LoRA 或参考图方案）；
4. 角色可命名、可换装（换装 = 后续付费点）。

**这是留存与付费的锚**：用户一旦养了角色，这个 App 就从"工具"变成"我的漫画分身"，迁移成本陡增。

## 六、逗比线条风格定义

风格是本产品的灵魂，必须被**显式定义并可执行**，而不是靠模型自由发挥。

### 6.1 视觉规范

| 维度 | 规范 |
|---|---|
| 线条 | 黑色主线条，粗细略带手抖感（模拟马克笔/针管笔），不追求工整 |
| 上色 | 默认黑白线稿；可选"马克笔淡彩"模式（≤3 种低饱和色块） |
| 角色造型 | 头身比 1:1 ~ 1:1.5，简笔五官，表情夸张化（豆豆眼、瀑布泪、黑线、红脸蛋） |
| 表情包符号 | 允许漫画符号：💢青筋、汗滴、石化裂纹、灵魂出窍 —— 这些是逗比感的来源 |
| 背景 | 极简或无背景，速度线/纯色块代替，突出人物和梗 |
| 禁忌 | 不画写实、不上厚涂、不搞渐变光影——"精致"是这个风格的敌人 |

### 6.2 叙事节奏规范（段子结构）

脚本生成遵循经典梗结构：

- **4 格**：起（铺垫）→ 承（推进）→ 转（意外）→ **爆（最后一格反转/吐槽，全图笑点）**；
- 最后一格优先用**大特写 + 死鱼眼/假笑/流泪竖拇指**等经典表情公式；
- 对白口语化，允许网络热梗但**避免当月过期烂梗**（梗库需要运营维护）。

### 6.3 风格资产建设

1. 收集 200~500 张目标风格参考图（注意版权：使用公有领域简笔漫画 + 自绘样本 + 授权素材）；
2. 训练 1~2 个风格 LoRA（基于 Flux/SDXL），作为自托管方案的底子；
3. 同步沉淀 API 方案的风格提示词模板（style prompt 作为商业机密管理）；
4. 建立风格评审卡：每周抽 50 张产出人工打分（风格符合度 / 好笑程度），持续迭代。

### 7.2 生成管线时序（关键路径）

```
用户输入 ──► 文本审核(~0.3s) ──► LLM脚本(~3-5s) ──► [首格先行]
                                                      │
            ◄── 首格预览 ◄── 第1格绘图(~8-15s) ◄───────┤
                                                      │
   并行：第2/3/4格绘图 ──► 气泡叠加+排版(~1s) ──► 图像审核
                                                      │
              ◄── 完整条漫（总耗时目标 25-40s）◄────────┘
```

**工程要点**：
- 脚本输出为**强约束 JSON**（每格：画面描述 / 角色动作 / 对白 / 镜头），用 LLM function calling / structured output，杜绝自由文本解析失败；
- 各格绘图并行发起，但**第 1 格最高优先级**（首格预览策略）；
- 角色参考图（character sheet）随每个绘图请求注入，保证跨格一致性（见第九章）；
- 任一环节失败自动重试 1 次，仍失败则降级（跳过该格用占位 or 整单重试），全程对用户透明（"第 3 格画崩了，正在重画…"）。

## 八、核心技术一：段子脚本与分镜生成

**这是决定"好不好笑"的环节，重要性 ≥ 画图。**

### 8.1 脚本器职责

输入一段用户想法，输出结构化分镜脚本：

```json
{
  "title": "老板的『借鉴』",
  "style": "逗比线条",
  "characters": [
    {"id": "me", "desc": "秃头打工人，黑眼圈，格子衫"},
    {"id": "boss", "desc": "中年领导，啤酒肚，油头"}
  ],
  "panels": [
    {"no": 1, "scene": "会议室，我兴奋地展示方案", "action": "我手舞足蹈讲PPT", "dialogue": "老板！我觉得这个方案绝了！", "camera": "中景"},
    {"no": 2, "scene": "老板摸着下巴点头", "action": "老板微笑", "dialogue": "不错不错，很有想法", "camera": "近景"},
```

### 8.2 脚本质量三原则

1. **反转优先**：prompt 中强制要求"最后一格必须有反转或情绪爆点"，并给出 10+ 种经典反转模板（期待落空、身份错位、因果报应、打破第四面墙…）；
2. **对白克制**：每格对白 ≤ 20 字，能靠画面表达的不用文字（漫画不是段子合集）；
3. **安全边界**：吐槽类内容自动做"去指向化"——骂老板可以，但不生成可识别的真实人名/公司名/侮辱性内容。

### 8.3 梗库运营（长期护城河）

- 建立结构化梗库：热梗、经典反转结构、高频场景（上班/恋爱/养猫/减肥…），作为 LLM 的 few-shot 示例动态注入；
- 每周人工更新，淘汰过气梗；
- 用户对成品的"再画一个/点赞"行为回流为梗质量标注，优质脚本沉淀进库。

## 九、核心技术二：图像生成与角色一致性

### 9.1 难点本质

连环图 ≠ 多张独立插画。用户一眼能看出的崩坏：
- 主角从第 1 格到第 4 格换了脸/换了衣服；
- 画风在格与格之间漂移；
- 同一场景里家具位置乱跳。

### 9.2 方案对比与选型

| 方案 | 一致性 | 成本 | 速度 | 可控性 | 结论 |
|---|---|---|---|---|---|
| **A1. Gemini 系图像模型（多图参考）** | ★★★★ | 中 | 快 | 中 | **MVP 首选**：原生支持多张参考图输入，角色一致性好，中文理解强 |
| **A2. GPT Image 系** | ★★★★ | 高 | 中 | 高（指令遵循强） | 备选/高质量模式 |
| **A3. 国产模型（即梦 Seedream 等）** | ★★★☆ | 低 | 快 | 中 | 成本敏感时降级方案，国内合规性好 |
| **B. 自托管 Flux/SDXL + 风格 LoRA + IP-Adapter** | ★★★☆（需打磨） | 低（规模化后） | 中 | 极高 | V2 主力：风格完全自控，成本摊薄，不受上游 API 约束 |

**策略：MVP 用 A1/A3 双供应商跑通产品，同步训练自有 LoRA；V2 把高频场景迁移到自托管，成本降 60%+ 且风格形成独家资产。**

### 9.3 角色一致性工程（核心 know-how）

1. **Character Sheet 先行**：脚本确定后，先生成一张角色设定图（正面全身 + 三视图 + 表情集），作为后续所有格的参考图注入；
2. **参考图注入**：每格绘图请求 = 风格提示词 + 角色设定图 + 本格画面描述（"character sheet 中的人物，保持完全一致的造型"）；
3. **提示词锁定**：角色的文字描述（秃头/格子衫/黑眼圈）在所有格提示词中逐字复用，禁止模型自由发挥；
4. **一致性校验（V1.1）**：用视觉模型对比各格主角相似度，低于阈值自动重绘该格（用户无感）；
5. **专属角色（5.5）**：付费用户上传照片后训练轻量 LoRA（或缓存参考图组），角色资产绑定账号。

### 9.4 风格一致性

- 所有格共享同一段风格前缀提示词（6.1 规范的文字化）+ 固定负面提示词（"写实、渐变、厚涂、精致光影"）；
- 自托管方案下风格由 LoRA 锁定，提示词只负责内容，风格漂移问题根除。

## 十、核心技术三：版式合成与对白气泡

**原则：对白文字绝不依赖图像模型生成**（中文渲染不可靠、错别字是致命伤），一律程序化叠加。

### 10.1 气泡引擎

- 脚本中每格的 `dialogue` 由排版引擎渲染为气泡图层，叠加到成品图上；
- 气泡样式库：普通圆泡、 shouting 爆炸泡（强调）、思考泡、无气泡纯旁白框；
- 字体：手写感中文字体（注意字体版权，采购商用授权，如汉仪/方正手写体系列）；
- 位置策略：优先放在画面留白区；无留白时自动加白色衬底；支持用户手动拖拽微调（编辑模式）。

### 10.2 排版引擎

- 条漫模板库：4 格田字 / 4 格竖排 / 6 格 2×3 / 不规则分格（V2）；
- 格间留白、边框样式（手抖边框与画风统一）、格号标注；
- 输出合成：条漫 + 九宫格拆分版（方便发朋友圈九图）+ 单格导出。

### 10.3 生成失败兜底

- 单格重试 1 次仍失败 → 用"该格画崩了"的自嘲占位图（本身是个梗，把事故变故事）；
- 全单失败 → 免费补一次 + 道歉文案；生成费用不进计费。

## 十二、内容安全与合规

这是 UGC + AIGC 产品的**生死线**，尤其输入端是用户自由想法。

| 环节 | 措施 |
|---|---|
| 输入文本 | 先过文本安全审核（涉政/色情/暴力/辱骂/广告），命中拒绝生成并提示；灰度词走脚本器"软化改写"（如侮辱性吐槽 → 无害化处理） |
| 脚本层 | prompt 内置红线约束；禁止生成真实公众人物恶搞、真实可识别的个人 |
| 图像生成 | 绘图提示词再过一次关键词过滤（防用户想法里的词直接进提示词） |
| 输出图像 | 成品图过图像安全审核后才可保存/分享；审核不通过 → 重绘或拦截 |
| 人脸参考（V1.1） | 上传他人照片需勾选"已获本人授权"；本人照片做活体确认；禁止生成真实人物的丑化/侮辱内容 |
| 数据合规 | 用户输入内容与生成作品仅用于服务本身；用作训练数据需单独授权（默认关闭） |
| AIGC 标识 | 按《人工智能生成合成内容标识办法》对输出图片添加显式/隐式 AIGC 标识 |
| 未成年人 | 注册年龄门槛 + 内容分级 |

**原则：宁可拦错，不可漏放。** 一次舆情事故足以杀死这类产品。

## 十三、成本估算

### 13.1 单次生成成本（4 格漫）

| 环节 | 方案 | 单价估算 | 小计 |
|---|---|---|---|
| 脚本 LLM | 国产模型 1 次调用 | ~0.01-0.05 元 | ~0.03 元 |
| 角色设定图 | API 1 次（可缓存复用） | ~0.1-0.3 元 | 首次 0.2 元，摊薄后≈0 |
| 4 格绘图 | API 中档模型 ×4 | ~0.1-0.35 元/张 | **0.4-1.4 元** |
| 安全审核 | 文本+图像 | ~0.01 元 | ~0.01 元 |
| **合计（API 方案）** | | | **约 0.5-1.5 元/次** |
| 自托管方案（V2，含 GPU 摊薄） | | | **约 0.05-0.15 元/次** |

（按 2026 年主流模型 API 公开价估算；实际以供应商报价为准，且模型降价趋势明显。）

### 13.2 单位经济模型（免费增值下）

- 假设免费用户 3 次/日，会员不限量（实际人均 ~15 次/日封顶）；
- 免费用户成本 ~2 元/日 → 必须靠裂变拉新价值 + 会员转化覆盖；
- **关键指标**：会员渗透率 ≥ 8% 时模型跑正（会员 19.9 元/月 ≈ 每日 0.66 元收入 vs 高频使用 ~1 元成本，需配合自托管降本 + 广告/增值收入）。
- 结论：**MVP 期烧钱换增长可接受，但自托管降本（13.1 末行）是商业模型成立的前提。**

## 十四、商业模式与增长

### 14.1 商业模式：免费增值（Freemium）

| 层级 | 内容 | 价格 |
|---|---|---|
| 免费 | 每日 3 次生成、4 格、带角标、基础风格 | 0 |
| 会员 | 不限量（有公平上限）、无水印、6/8 格、全风格、高清多比例导出 | 19.9 元/月 或 128 元/年 |
| 增值 1 | 专属角色训练（照片 → 你的漫画分身） | 9.9 元/个 或会员免费 |
| 增值 2 | 角色换装包、节日限定风格包 | 6 元/包 |
| 增值 3（V2） | 周边实物：贴纸、冰箱贴、帆布包（按需印刷，无库存） | 19-59 元/件 |
| B 端（远期） | 品牌定制漫（企业号宣传漫、门店引流梗图） | 按单报价 |

### 14.2 增长策略（冷启动三板斧）

1. **水印即广告**：免费版的角标设计成可爱的"脑洞成漫"小角色，分享出去就是广告位；
2. **小红书内容矩阵**：官方账号日更"打工人吐槽漫""养猫沙雕漫"系列，评论区引导"你的经历也能画"，配小程序码；抖音同步搬运 + 生成过程录屏（进度梗文案本身就是视频素材）；
3. **裂变机制**：邀请好友注册各得 3 次生成额度；"帮 TA 画一张"分享链接（好友点开输入想法，双方得额度）。

### 14.3 留存设计

- 每日灵感卡（给理由打开）；
- 专属角色 + 作品收藏（资产沉淀）；
- 周报彩蛋："本周你的漫画人生"（每周日汇总本周作品生成一张回顾图）。

- 高分享作品脚本沉淀进梗库 → 越用越好笑的飞轮。

## 附录 A：一页速览（给忙碌的决策者）

> **做什么**：输入一段想法 → 30 秒自动生成逗比线条风 4 格连环图，可分享。
> **为什么能成**：图像模型一致性刚过可用拐点 + 简笔风是 AI 甜区 + 社交梗图需求旺盛。

> **MVP**：微信小程序，6-8 周，4 人团队，先跑通"好笑"这一个点。
> **花钱**：API 期 ~1 元/次，自托管后 ~0.1 元/次；会员 19.9/月覆盖重度用户。
> **最大风险**：不好笑。所以 Phase 0 只验证一件事——AI 画的梗，人看了想不想转发。
