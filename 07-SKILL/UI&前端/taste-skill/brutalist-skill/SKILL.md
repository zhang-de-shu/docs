# 技能：工业粗野主义与战术遥测 UI

## 1. 技能元信息
**名称：** 工业粗野主义与战术遥测界面工程
**描述：** 精通构建融合世纪中期瑞士排版设计、工业制造手册与复古未来主义航空航天/军事终端界面的 Web 界面。这门学科要求对刚性模块化网格、极端的字体层级对比、纯粹功能主义的配色方案，以及对模拟退化效果（半调、CRT 扫描线、位图抖动）的程序化模拟具备绝对的掌控力。其目标是构建能够传达原始功能性、机械精度与高数据密度的数字环境，并刻意抛弃常规的消费级 UI 模式。

## 2. 视觉原型
该设计系统通过融合两种截然不同但高度兼容的视觉范式来运作。**每个项目只选择其中一种并坚持到底。不要在同一界面中交替或混合使用两种模式。**

### 2.1 瑞士工业印刷
源自 1960 年代的企业识别系统与重型机械蓝图。
*   **特征：** 高对比度的亮色模式（新闻纸/米白色基材）。依赖厚重、整体的无衬线字体。由可见分割线勾勒出的严酷结构性网格。激进的不对称负空间运用，点缀以超大号、溢出视口的数字或字母。大量使用原色红作为警示/强调色。

### 2.2 战术遥测与 CRT 终端
源自机密军事数据库、传统大型机与航空航天平视显示器（HUD）。
*   **特征：** 专属于暗色模式。高密度的表格数据呈现。等宽字体的绝对主导地位。技术性取景框元素（ASCII 括号、十字准星）的整合。模拟硬件限制的应用（荧光辉光、扫描线、低色深渲染）。

## 3. 字体排印架构
字体排印是首要的结构性与装饰性基础设施。图像居于次要地位。该系统要求在字号、字重与间距上有极端的变化。

### 3.1 宏观字体排印（结构性标题）
*   **分类：** 新怪诞体 / 重型无衬线体。
*   **最佳 Web 字体：** Neue Haas Grotesk (Black)、Inter (Extra Bold/Black)、Archivo Black、Roboto Flex (Heavy)、Monument Extended。
*   **实施参数：**
    *   **字号：** 使用流式字体排印部署在巨大尺度上（例如 `clamp(4rem, 10vw, 15rem)`）。
    *   **字距（Letter-spacing）：** 极紧，通常为负值（`-0.03em` 至 `-0.06em`），迫使字形形成坚实的建筑块面。
    *   **行距（Line-height）：** 高度压缩（`0.85` 至 `0.95`）。
    *   **大小写：** 为了结构冲击力，一律使用全大写。

### 3.2 微观字体排印（数据与遥测）
*   **分类：** 等宽体 / 技术性无衬线体。
*   **最佳 Web 字体：** JetBrains Mono、IBM Plex Mono、Space Mono、VT323、Courier Prime。
*   **实施参数：**
    *   **字号：** 固定且小（`10px` 至 `14px` / `0.7rem` 至 `0.875rem`）。
    *   **字距：** 宽松（`0.05em` 至 `0.1em`），以模拟机械打字机间距或终端字符矩阵。
    *   **行距：** 标准到紧（`1.2` 至 `1.4`）。
    *   **大小写：** 一律全大写。用于所有元数据、导航、单元 ID 与坐标。

### 3.3 质感对比（艺术性破坏）
*   **分类：** 高对比度衬线体。
*   **最佳 Web 字体：** Playfair Display、EB Garamond、Times New Roman。
*   **实施参数：** 使用必须极度克制。必须经过大量后处理（半调滤镜、1-bit 抖动）以破坏矢量的完美感，与干净的无衬线体形成质感上的并置。

## 4. 色彩系统
色彩架构毫不妥协。渐变、柔和投影与现代半透明效果被严格禁止。色彩模拟物理介质或原始发光显示器。

**关键：每个项目选择一种基材配色并一致使用。绝不在同一界面中混用亮色与暗色基材。**

### 如果使用瑞士工业印刷（亮色）：
*   **背景：** `#F4F4F0` 或 `#EAE8E3`（哑光、未漂白的文档纸）。
*   **前景：** `#050505` 至 `#111111`（碳素墨水）。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险警示红）。这是唯一的强调色。用于删除线、粗重的结构分割线或关键数据高亮。

### 如果使用战术遥测（暗色）：
*   **背景：** `#0A0A0A` 或 `#121212`（关闭的 CRT。避免纯 `#000000`）。
*   **前景：** `#EAEAEA`（白色荧光）。这是主要文字颜色。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险警示红）。同样的红色，同样的规则。
*   **终端绿（`#4AF626`）：** 可选。仅用于单一的特定 UI 元素（例如一个状态指示器或一个数据读数）——绝不作为通用文字颜色。如果它没有明确用途，就完全省略。

## 5. 布局与空间工程
布局必须看起来像是经过数学工程化设计的。它拒绝常规的 Web 内边距，转而采用可见的分区化。

*   **蓝图网格：** 严格遵循 CSS Grid 架构。元素不是漂浮的；它们被精确锚定在网格轨道与交点上。
*   **可见的分区化：** 大量使用实线边框（`1px` 或 `2px solid`）来划分不同的信息区域。水平分割线（`<hr>`）经常横跨整个容器宽度以分隔操作单元。
*   **双模密度：** 布局在极端的数据密度（紧密聚集的等宽元数据簇）与围绕宏观字体排印的大面积刻意留白之间摆动。
*   **几何形状：** 绝对拒绝 `border-radius`。所有转角必须恰好为 90 度，以强制呈现机械刚性。

## 6. UI 组件与符号系统
标准 Web UI 惯例被功能主义的工业图形元素所取代。

*   **语法装饰：** 使用 ASCII 字符为数据点取景。
    *   *取景框：* `[ DELIVERY SYSTEMS ]`、`< RE-IND >`
    *   *方向性：* `>>>`、`///`、`\\\\`
*   **工业标记：** 醒目地整合注册符号（`®`）、版权符号（`©`）与商标符号（`™`），使其作为结构性几何元素而非法律文本发挥作用。
*   **技术资产：** 在网格交点整合十字准星（`+`）、重复的垂直线（条形码）、粗重的水平警示条纹，以及随机字符串数据（例如 `REV 2.6`、`UNIT / D-01`），以模拟活跃的机械过程。

## 7. 质感与后处理效果
为了防止设计显得纯粹数字化，通过 CSS 与 SVG 滤镜将模拟的模拟信号退化效果工程化地注入前端。

*   **半调与 1-Bit 抖动：** 将连续色调图像或大号衬线字体转化为点阵图案。通过预处理或 CSS `mix-blend-mode: multiply` 叠加结合 SVG 径向圆点图案实现。
*   **CRT 扫描线：** 对于终端界面，对背景应用 `repeating-linear-gradient` 以模拟水平电子束扫描（例如 `repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`）。
*   **机械噪点：** 在 DOM 根节点应用全局、低不透明度的 SVG 静态/噪点滤镜，为暗色与亮色模式引入统一的物理颗粒感。

## 8. Web 工程指令
1.  **网格确定性：** 使用 `display: grid; gap: 1px;` 配合对比鲜明的父子背景色，生成数学上完美的极细分割线，而无需复杂的边框声明。
2.  **语义刚性：** 使用精确的语义标签（`<data>`、`<samp>`、`<kbd>`、`<output>`、`<dl>`）构建 DOM，以准确反映遥测数据的技术本质。
3.  **字体钳制：** 仅对宏观字体排印实施 CSS `clamp()` 函数，确保巨大的文字在跨视口激进缩放的同时保持结构完整性。
