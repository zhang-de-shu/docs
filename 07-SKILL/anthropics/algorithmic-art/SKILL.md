算法理念是一种计算美学思潮，随后通过代码加以表达。输出 .md 文件（理念）、.html 文件（交互式查看器）和 .js 文件（生成式算法）。

这分两步进行：
1. 算法理念创作（.md 文件）
2. 通过创作 p5.js 生成式艺术来加以表达（.html + .js 文件）

首先，着手这项任务：

## 算法理念创作

首先，创作一个算法理念（ALGORITHMIC PHILOSOPHY，而非静态图像或模板），它将通过以下方式被诠释：
- 计算过程、涌现行为、数学之美
- 带种子的随机性、噪声场、有机系统
- 粒子、流动、场、力
- 参数化变化与受控的混沌

### 关键的理解
- 收到的是什么：用户提供的一些微妙的输入或指示，需要纳入考虑，但仅作为基础；它不应限制创作自由。
- 创作的是什么：一种算法理念/生成式美学思潮。
- 接下来会发生什么：同一个版本会接收这份理念并用代码将其表达出来——创作 90% 为算法生成、10% 为核心参数的 p5.js 草图。

考虑这样的思路：
- 为一场生成式艺术运动撰写一份宣言
- 下一阶段则涉及编写让它焕发生命的算法

理念必须强调：算法化的表达。涌现行为。计算之美。带种子的变化。

### 如何生成一份算法理念

**为运动命名**（1-2 个词）："Organic Turbulence" / "Quantum Harmonics" / "Emergent Stillness"

**阐述理念**（4-6 段——简洁但完整）：

为捕捉其算法本质，请表达这一理念如何通过以下方式体现：
- 计算过程与数学关系？
- 噪声函数与随机性模式？
- 粒子行为与场的动态？
- 时间上的演化与系统状态？
- 参数化变化与涌现的复杂性？

**关键准则：**
- **避免冗余**：每个算法层面的方面都应只提及一次。除非能增添新的深度，否则不要重复噪声理论、粒子动力学或数学原理相关的概念。
- **反复强调匠心**：理念必须多次强调，最终的算法应当看起来像是花费了无数小时开发、经过精心打磨、出自该领域顶尖高手之手。这一定调至关重要——反复使用诸如 "meticulously crafted algorithm"、"the product of deep computational expertise"、"painstaking optimization"、"master-level implementation" 之类的措辞。
- **留出创作空间**：对算法方向要具体，但又要足够简洁，让下一个 Claude 有余地以极高的匠心水平做出诠释性的实现选择。

理念必须引导下一个版本以算法方式表达思想，而非通过静态图像。美存在于过程之中，而非最终定格的画面。

### 理念示例

**"Organic Turbulence"**
理念：混沌被自然法则约束，秩序自无序中涌现。
算法化表达：由多层 Perlin 噪声驱动的流场。成千上万的粒子沿矢量力运动，其轨迹累积成有机的密度图。多个噪声八度（octave）造就出湍急区域与平静区域。颜色由速度和密度涌现——快速的粒子灼灼发亮，缓慢的粒子淡入阴影。算法运行直至达到平衡——一种经过精心调校的平衡，其中每个参数都由一位计算美学大师经过无数次迭代打磨而成。

**"Quantum Harmonics"**
理念：离散的实体呈现出类波的干涉图样。
算法化表达：粒子在网格上初始化，每个都携带一个通过正弦波演化的相位值。当粒子彼此靠近时，它们的相位发生干涉——相长干涉造就明亮的节点，相消干涉造就空洞。简谐运动生成复杂而涌现的曼陀罗。这是经过煞费苦心的频率校准的成果，其中每一个比率都经过精心选择以产生共鸣之美。

**"Recursive Whispers"**
理念：跨尺度的自相似，有限空间中的无限深度。
算法化表达：递归细分的分支结构。每根分支略有随机，但受黄金比例约束。L 系统或递归细分生成既数学化又有机的树状形态。细微的噪声扰动打破了完美的对称。线宽随每一层递归而递减。每一个分支角度都是深度数学探索的产物。

**"Field Dynamics"**
理念：无形之力通过其对物质的作用而显现。
算法化表达：由数学函数或噪声构造出的矢量场。粒子诞生于边缘，沿场线流动，在到达平衡或边界时消亡。多个场可以吸引、排斥或旋转粒子。可视化只呈现痕迹——无形之力的幽灵般的证据。一场经由力的平衡精心编排的计算之舞。

**"Stochastic Crystallization"**
理念：随机过程结晶为有序结构。
算法化表达：随机化的圆形填充或 Voronoi 镶嵌。以随机点开始，让它们通过松弛算法演化。单元格相互推挤直至平衡。颜色基于单元格大小、邻居数量或到中心的距离。涌现出的有机镶嵌感觉既随机又必然。每一颗种子都产生独一无二的结晶之美——大师级生成式算法的印记。

*以上是浓缩的示例。真正的算法理念应为 4-6 段实质性的文字。*

### 核心原则
- **算法理念**：创造一种要通过代码表达的计算世界观
- **过程重于产物**：始终强调美从算法的执行中涌现——每一次运行都是独一无二的
- **参数化表达**：思想通过数学关系、力、行为来传达——而非通过静态构图
- **艺术自由**：下一个 Claude 以算法方式诠释理念——请留出创作性的实现空间
- **纯粹的生成式艺术**：这关乎创造活生生的算法，而非带随机性的静态图像
- **专家级匠心**：反复强调最终算法必须让人感到经过精心打磨、历经无数次迭代，是计算美学领域顶尖高手深厚功力的产物

**算法理念应为 4-6 段。** 用富有诗意的计算哲学充实它，将预期愿景汇聚起来。避免重复相同的要点。将这份算法理念输出为一个 .md 文件。

**核心算法——表达理念**：

**关键**：应当由算法理念来决定构建什么。

要通过代码表达理念，请避免思考"我该用哪种图案？"，而应思考"如何通过代码表达这份理念？"

如果理念关乎**有机涌现**，可考虑使用：
- 随时间累积或生长的元素

- 几何关系与比例
- 三角函数与谐波

- 严格边界内的随机变化

- 自无序中涌现的秩序

## 交互式制品创作

**提醒：应已阅读过 `templates/viewer.html`（见步骤 0）。以该文件为起点。**

为便于探索生成艺术，创建一个单一、自包含的 HTML 制品。确保该制品可在 claude.ai 或任何浏览器中立即运行——无需任何设置。将一切内联嵌入。

### 关键：哪些是固定的、哪些是可变的

`templates/viewer.html` 文件是基础。它包含所需的确切结构和样式。

**固定（FIXED，始终完全按原样包含）：**
- 布局结构（页眉、侧边栏、主画布区域）
- Anthropic 品牌形象（UI 颜色、字体、渐变）
- 侧边栏中的 Seed 部分：
  - 种子显示
  - Previous/Next 按钮
  - Random 按钮
  - Jump to seed 输入框 + Go 按钮
- 侧边栏中的 Actions 部分：
  - Regenerate 按钮
  - Reset 按钮

**可变（VARIABLE，为每件作品定制）：**
- 整个 p5.js 算法（setup/draw/类）
- 参数对象（定义该艺术所需的内容）
- 侧边栏中的 Parameters 部分：
  - 参数控件的数量
  - 参数名称
  - 滑块的最小值/最大值/步长
  - 控件类型（滑块、输入框等）
- Colors 部分（可选）：
  - 有些作品需要颜色选择器
  - 有些作品可能使用固定颜色
  - 有些作品可能是单色的（无需颜色控件）
  - 根据作品的需要来决定

**每件作品都应有独特的参数和算法！** 固定部分提供一致的用户体验——其余一切都在表达那份独特的愿景。

### 必备功能

**1. 参数控件**
- 用于数值参数的滑块（粒子数量、噪声尺度、速度等）
- 用于调色板颜色的颜色选择器
- 参数改变时的实时更新
- 用于恢复默认值的 Reset 按钮

**2. 种子导航**
- 显示当前种子编号
- 用于循环切换种子的 "Previous" 和 "Next" 按钮
- 用于随机种子的 "Random" 按钮
- 用于跳转到特定种子的输入框
- 应要求时生成 100 个变体（种子 1-100）

**3. 单一制品结构**
```html
<!DOCTYPE html>
<html>
<head>
  <!-- p5.js from CDN - always available -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.7.0/p5.min.js"></script>
  <style>
    /* All styling inline - clean, minimal */
    /* Canvas on top, controls below */
  </style>
</head>
<body>
  <div id="canvas-container"></div>
  <div id="controls">
    <!-- All parameter controls -->
  </div>
  <script>
    // ALL p5.js code inline here
    // Parameter objects, classes, functions
    // setup() and draw()
    // UI handlers
    // Everything self-contained
  </script>
</body>
</html>
```

**关键**：这是一个单一的制品。没有外部文件，没有导入（p5.js CDN 除外）。一切内联。

**4. 实现细节——构建侧边栏**

侧边栏结构：

**1. Seed（固定）**——始终完全按原样包含：
- 种子显示
- Prev/Next/Random/Jump 按钮

**2. Parameters（可变）**——为该艺术创建控件：
```html
<div class="control-group">
    <label>Parameter Name</label>
    <input type="range" id="param" min="..." max="..." step="..." value="..." oninput="updateParam('param', this.value)">
    <span class="value-display" id="param-value">...</span>
</div>
```
有多少个参数，就添加多少个 control-group div。

**3. Colors（可选/可变）**——如果该艺术需要可调节的颜色则包含：
- 如果用户应能控制调色板，则添加颜色选择器
- 如果该艺术使用固定颜色，则跳过此部分
- 如果该艺术是单色的，则跳过

**4. Actions（固定）**——始终完全按原样包含：
- Regenerate 按钮
- Reset 按钮
- Download PNG 按钮

**要求**：
- 种子控件必须能工作（prev/next/random/jump/display）
- 所有参数都必须有 UI 控件
- Regenerate、Reset、Download 按钮必须能工作
- 保留 Anthropic 品牌形象（UI 样式，而非艺术色彩）

### 使用制品

该 HTML 制品可立即运行：
1. **在 claude.ai 中**：以交互式制品的形式显示——即刻运行
2. **作为文件**：保存后在任何浏览器中打开——无需服务器
3. **分享**：发送该 HTML 文件——它是完全自包含的

## 创作过程

**用户请求** → **算法理念** → **实现**

每个请求都是独一无二的。该过程包括：

1. **诠释用户的意图**——他们在追求怎样的美学？
2. **创作一份算法理念**（4-6 段），描述其计算方法
3. **用代码实现它**——构建能表达该理念的算法
4. **设计合适的参数**——什么应当是可调的？
5. **构建相配的 UI 控件**——为那些参数配上滑块/输入框

**恒定不变的部分**：
- Anthropic 品牌形象（颜色、字体、布局）
- 种子导航（始终存在）
- 自包含的 HTML 制品

**其余一切皆可变**：
- 算法本身
- 参数
- UI 控件
- 视觉结果

要取得最佳成果，请信任自己的创造力，让理念来引导实现。
