# Theme Factory 技能

本技能提供一套精心策划的专业字体与配色主题集合，每个主题都配有精挑细选的配色方案和字体搭配。选定主题后，即可将其应用到任意 artifact 上。

## 目的

若要为演示幻灯片赋予一致、专业的样式，请使用本技能。每个主题包含：
- 一套配有十六进制色值的协调配色方案
- 用于标题和正文的互补字体搭配
- 适用于不同场景和受众的鲜明视觉风格

## 使用说明

若要为幻灯片或其他 artifact 应用样式：

1. **展示主题一览**：显示 `theme-showcase.pdf` 文件，让用户可以直观地查看所有可用主题。不要对它做任何修改，只需展示文件供查看。
2. **询问用户的选择**：询问要将哪个主题应用到幻灯片上
3. **等待选择**：获得关于所选主题的明确确认
4. **应用主题**：确定主题后，将所选主题的颜色和字体应用到幻灯片/artifact 上

## 可用主题

以下 10 个主题均可使用，每一个都在 `theme-showcase.pdf` 中展示：

1. **Ocean Depths** - 专业而沉静的海洋主题
2. **Sunset Boulevard** - 温暖而鲜明的落日色彩
3. **Forest Canopy** - 自然而沉稳的大地色调
4. **Modern Minimalist** - 简洁而现代的灰阶
5. **Golden Hour** - 浓郁而温暖的秋日配色
6. **Arctic Frost** - 清冷而凛冽的冬季主题
7. **Desert Rose** - 柔和而精致的雾感色调
8. **Tech Innovation** - 大胆而现代的科技美学
9. **Botanical Garden** - 清新而自然的花园色彩
10. **Midnight Galaxy** - 戏剧化而宇宙感的深邃色调

## 主题详情

每个主题都在 `themes/` 目录中定义，包含完整规格：
- 配有十六进制色值的协调配色方案
- 用于标题和正文的互补字体搭配
- 适用于不同场景和受众的鲜明视觉风格

## 应用流程

选定首选主题后：
1. 从 `themes/` 目录读取对应的主题文件
2. 在整个幻灯片中一致地应用指定的颜色和字体
3. 确保恰当的对比度和可读性
4. 在所有幻灯片中保持该主题的视觉风格

## 创建你自己的主题
若现有主题都不适合某个 artifact，可创建自定义主题。根据提供的输入，生成一个与上述主题类似的新主题。为主题取一个类似的名字，用以描述其字体/颜色组合所代表的意涵。根据提供的任何基本描述来选择合适的颜色/字体。生成主题后，展示它以供审阅和确认。随后，按上文所述应用该主题。
