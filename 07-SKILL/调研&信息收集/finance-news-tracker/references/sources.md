# 财经与市场信息源地图

## 源层级（务必遵守）

**条目主来源只能用权威源。** 层级如下，越靠前越优先：

1. **官方数据发布 + 公司公告（数据类首选）**：统计局、央行、美联储、交易所、公司公告/招股书。数字以此为准。
2. **权威财经媒体（主来源）**：彭博、路透、WSJ、FT、CNBC、财新。事实性强、时间戳可靠。
3. **数据终端与行情源（行情/量化数据）**：TradingView、Investing.com、Wind/东财（行情与经济日历）。
4. **分析师/机构观点（标注为观点，不作事实源）**：券商研报、机构预测、评级——一律标"（某机构观点）"，绝不写成定论，绝不作简报的行动指引。
5. **小道消息/传闻（仅发现线索）**：财经博主、社群消息。**绝不单独作主来源**，发现线索后回上层核实，拿不到权威来源就丢弃或标"据传，待证实"。

---

按"权威财经媒体 → 官方数据源 → 交易所与监管 → 数据终端 → 中文源 → 检索技巧"组织。每条标注**擅长抓什么**和**怎么访问**。

这份地图会随市场演变而变化——发现某源长期失效或质量下滑就更新，发现新的高质量源就加进来。不是权威清单，是起点。

## 六、检索技巧

- **Google 时间限制**：限定"过去 24 小时 / 7 天"，把旧闻过滤掉；区分交易日。
- **site: 操作符**：`site:reuters.com <关键词>`、`site:sec.gov <ticker>`、`site:cninfo.com.cn <公司名>`。
- **英文检索式**：`<index> close today`、`Fed rate decision <month>`、`US CPI <month> actual`、`<ticker> Q<x> earnings`、`China PMI <month>`。
- **中文检索式**：`A股 收盘 <日期>`、`<数据名> 公布 <月份>`、`北向资金 <日期>`、`<公司名> 财报`。
- **数据核对**：宏观数据回统计局/BLS/官方，公司数字回巨潮/EDGAR/公司公告，行情回交易所/TradingView。
- **经济日历**：用 Investing.com 经济日历提前知道当天有哪些数据发布及其预期值。
- **工具优先级**：内置 `search` 最稳作主力；`WebSearch` 备用，失败不重试直接换 `search`；有 URL 用 `WebFetch`；看行情页/数据日历用 `browser` navigate + snapshot。

## 检索节奏建议

一次完整每日简报大概 5-7 次检索，覆盖：
1. 权威财经媒体市场版（彭博/路透/CNBC，看隔夜美股与全球）
2. 经济日历（Investing，看当天有无重要数据/央行事件）
3. A 股/港股行情（东财/财新，看当日或最近交易日收盘）
4. 官方数据发布（若当期有宏观数据出炉，回官方核对三个数）
5. 重大公司公告/财报（巨潮/EDGAR，若有龙头财报）
6. 针对用户聚焦主题的定向检索（若有）

不要为凑次数搜无关的——召回质量比数量重要，数字准确比时效更重要。宁可不写具体数字，也不写错数字。
