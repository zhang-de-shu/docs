# 每日财经追踪器

这个 skill 的职责是：追踪**财经与市场领域的每日大事**——宏观数据、货币政策、市场行情、公司与产业、政策监管——把散落各处的事实去重、归类，产出一份每条都带**事实、简短市场影响、一手来源链接**的结构化 Markdown 简报。

**它的定位是"帮你了解市场"。** 重心是 **A 股/港股行情与政策 + 全球宏观（美股、美联储、大宗商品、汇率）**，因为国内投资者既要盯本土市场，也要看牵动它的全球变量。

检索日期范围：默认昨天（日报）

## 覆盖范围

按下面几层组织，凡是落进这个圈的事件都收：

1. **宏观数据与政策**：重要经济数据（GDP/CPI/PPI/PMI/就业/社融/进出口）、央行动向（美联储/央行利率决议、公开市场操作）、财政政策
2. **市场行情**：A 股/港股/美股/欧股/日股主要指数昨日与当日表现、板块轮动、北向/南向资金、成交量异动、重大回调或反弹
3. **大宗与外汇**：原油、黄金、工业金属、农产品价格异动；美元指数、人民币汇率、主要货币对；加密资产重大波动
4. **债市与利率**：国债收益率变化、信用事件、利差异动
5. **公司与产业**：重大财报、并购重组、IPO、龙头公司重大事项、产业链关键动向（对相关板块有市场含义的）
6. **政策与监管**：影响市场的监管新规、行业政策、关税与贸易、地缘经济事件（制裁的经济面）

## 工作流程

每次调用按四步走。**不要主动追问范围**——用户会自己说清楚；用户没说的部分用合理默认值直接执行。

### 第 1 步：分源检索

信息源完整地图见 `references/sources.md`，**每次都要读它**——它按"权威财经媒体 → 官方数据源 → 交易所与监管 → 数据终端 → 中文源 → 检索技巧"分类，并标注每个源擅长抓什么和访问方式。

检索时遵循这些原则（前两条是硬性门槛）：

- **权威来源是入场券**：每条事件**必须**至少有一个权威来源——权威财经媒体（彭博/路透/WSJ/FT/CNBC）、官方数据发布（统计局/央行/美联储/交易所）、公司公告。**小道消息、无出处"传闻"不入简报**，除非多源交叉且明确标注"据传，待证实"。
- **数据以官方为准**：宏观数据、公司财报数字一律以官方发布/公司公告为准，媒体转述的数字要回官方核对。区分"实际值/预期值/前值"，市场反应往往取决于是否超预期。
- **区分事实与观点**：数据、政策决议、公司公告是事实；分析师评级、机构预测、财经博主观点是观点——观点一律标注"（某机构观点）"，绝不写成定论，更不作为简报的行动指引。
- **时间窗内**：只收用户指明时间窗口内的事件。默认昨日（含美股收盘）。拿不准时间时信任官方发布时间与媒体时间戳，不信任模糊的"近日"。
- **并行检索**：内置 `search` 工具为主力（实测在 Cowork 环境最稳、召回新鲜中文效果好）；`WebSearch` 作备用（部分环境不可用，失败时不要重试，直接换 `search`）；有明确 URL 时用 `WebFetch` 抓详情；要看行情页/数据日历时用内置 `browser` navigate + snapshot。
- **检索式技巧**：英文用 `<index> close today`、`Fed rate decision <month>`、`<ticker> earnings`；追数据用 `US CPI <month> actual`、`China PMI <month>`；Google 时间范围限过去 24 小时/7 天。

### 第 2 步：综合去重

把检索到的零散信息合并：

- 同一事件多源 → 合并为一条，记一手/官方出处
- 按覆盖范围的层归类
- 按"影响面 × 意外程度 × 新鲜度"排序：牵动大盘的宏观/政策大事靠前，个股小事靠后。**超预期程度**是关键——符合预期的数据影响小，大幅超/不及预期的靠前。
- 诚实标注：预测/评级标"某机构观点"；传闻标"据传，待证实"，不要写成定论

### 第 3 步：保存 Markdown 简报


1. 保存路径
- 日报情况下（默认）：取`昨日日期`构建文件名 `财经简报-<日期>.md`
- 其他情况（多日）：`财经简报-<起始>_<结束>.md`（结束日期取昨日）
- 存到当前工作目录下的 `docs/00-每日简报/简报-财经/` 文件夹

2. 质量底线
- **每条至少一个权威来源**（权威财经媒体/官方数据/交易所/公司公告）。小道消息、无出处"传闻"不入简报，除非多源交叉且标"据传，待证实"。
- **数据以官方为准，标全三个数**。宏观数据带"实际/预期/前值"，财报带关键财务数字与超预期与否——市场反应取决于是否超预期。
- **区分事实与观点**。数据、决议、公告是事实；分析师评级、机构预测、博主观点是观点，一律标"（某机构观点）"，不写成定论。
- **不编造**。检索不到足够权威来源就如实说"本期权威来源有限"，不要为凑模板编造数据、事件或链接。数字拿不准宁可不写具体值。
- **日期核对**。涉及"今天""昨日""最新"的表述，先用 Bash 获取当前系统时间核对，区分交易日；不信任媒体模糊的"近日"。


3. 简报模板

每个条目**必须**包含三要素：事实（含关键数字）、简短市场影响、一个或多个来源链接。这是本 skill 的核心输出约定，务必照做。**影响写"对某类资产/板块的客观可能影响"，绝不做买卖建议、目标价或推荐。**
章节按覆盖范围的层分，**不是所有章节每期都要有**——本期哪层有大事就出哪节，没有就省掉，不要硬凑。但"一句话概览"和"市场行情"通常都要有。上面的章节只是示例，实际按本期内容灵活命名和组合。
条目格式说明：
- **事实**回答"发生了什么、关键数字是多少"——宏观数据必带"实际/预期/前值"三个数，财报必带营收/利润与超预期与否。
- **影响**：本 skill 区别于纯行情播报的价值——用 1-2 句给"对某类资产/板块的客观可能影响"，帮读者理解这件事为什么重要。**只写可能影响与客观归因，绝不预测点位、不给评级/目标价、不做任何买卖建议。**
- **来源**必须权威（财经媒体/官方数据/交易所/公司公告）；小道消息不作主来源。分析师观点标"（某机构观点）"。

```markdown
# 每日财经简报 · <日期，如 2026-08-03>

> 视角：A股 + 全球宏观

## 一句话概览
<2-3 句话，点出本期最牵动市场的 1-2 件大事及其大致影响>

## 宏观数据与政策
- **<数据/政策名，如某国 CPI / 某央行利率决议>**
  - 事实：<实际值 vs 预期值 vs 前值；政策决议内容；发布方与时间>
  - 影响：<对利率/汇率/相关资产的客观可能影响，1-2 句，不给建议>
  - 来源：[官方发布](url) ｜ [权威财经媒体](url)

## 市场行情（昨日 + 当日）
- **<市场/指数，如 A股 / 美股三大指数 / 港股>**
  - 事实：<指数涨跌幅、成交量、领涨领跌板块、资金流向等关键数字>
  - 影响/归因：<驱动因素的客观归因，1-2 句，不预测后市>
  - 来源：[财经媒体](url) ｜ [交易所](url)

## 大宗商品与外汇
- **<品种，如原油 / 黄金 / 人民币汇率>**
  - 事实：<价格、涨跌幅、驱动事件>
  - 影响：<对相关产业链/资产的可能影响>
  - 来源：...

## 债市与利率
- **<国债收益率 / 信用事件>** — <一句话事实 + 影响，带来源>

## 公司与产业
- **<公司/产业事件，如重大财报/并购/IPO>**
  - 事实：<关键数字：营收/利润/超预期与否；事件内容>
  - 影响：<对公司或所属板块的客观可能影响，不给评级、不给目标价>
  - 来源：[公司公告](url) ｜ [财经媒体](url)

## 政策与监管
- **<监管新规/行业政策/关税>** — <一句话事实 + 对相关板块的可能影响，带官方/权威链接>
```
