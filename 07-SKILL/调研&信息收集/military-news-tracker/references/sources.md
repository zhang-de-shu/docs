# 军事与地缘安全信息源地图

## 源层级（务必遵守）

**条目主来源只能用可信源。** 层级如下，越靠前越优先：

1. **权威通讯社 + 官方声明（条目主来源首选）**：路透、法新、美联、彭博、官方国防部/军方/政府声明。事实性最强。
2. **专业防务媒体（主来源，专业细节强）**：Defense News、Janes、The War Zone、Breaking Defense、Naval News 等。
3. **成熟智库与 OSINT（分析 + 交叉验证）**：ISW、CSIS、IISS、Bellingcat、可信开源情报。作分析补充与地面核实。
4. **社媒/网传（仅发现线索）**：X 上的 OSINT 账号、Telegram 频道等。**绝不单独作主来源**——假消息与宣传极多。发现线索后回上面三层核实，拿不到可信来源就丢弃或标"待证实"。

---

按"通讯社 → 防务媒体 → 智库/OSINT → 官方源 → 中文源 → 检索技巧"组织。每条标注**擅长抓什么**和**怎么访问**。

这份地图会随局势演变而变化——发现某源长期失效或质量下滑就更新，发现新的高质量源就加进来。不是权威清单，是起点。

## 六、检索技巧

- **Google 时间限制**：限定"过去 24 小时 / 7 天"，把旧闻过滤掉。
- **site: 操作符**：`site:reuters.com <关键词>`、`site:understandingwar.org`、`site:twz.com <装备名>`。
- **英文检索式**：`<region> conflict latest`、`<weapon name> deployed`、`military exercise <country> <month>`、`<country> defense budget <year>`。
- **中文检索式**：`<地区> 局势 最新`、`<国家> 军演`、`<武器名> 列装`。
- **多语言回译**：中文搜不到的用英文/当地语再搜（俄乌冲突可搜英文/俄文，中东搜英文/阿拉伯文关键地名）。
- **影像核实**：涉及现场影像/卫星图，优先 Bellingcat/TWZ 这类做过地理定位核实的来源。
- **工具优先级**：内置 `search` 最稳作主力；`WebSearch` 备用，失败不重试直接换 `search`；有 URL 用 `WebFetch`；看首页/每日更新列表用 `browser` navigate + snapshot。

发现某子领域本期无大事就跳过对应章节，不要硬凑。

## 检索节奏建议

一次完整每日简报大概 5-7 次检索，覆盖：
1. 通讯社世界版首页（路透/AP/半岛，看隔夜突发）
2. ISW / OSINT 每日战况更新（若有活跃冲突）
3. 专业防务媒体（TWZ/Defense News，看装备与部署）
4. 官方声明（有无重大声明/演习通告）
5. 中文源首页（参考消息/观察者，发现线索）
6. 针对用户聚焦主题的定向检索（若有）

不要为凑次数搜无关的——召回质量比数量重要，可信度比时效更重要。
