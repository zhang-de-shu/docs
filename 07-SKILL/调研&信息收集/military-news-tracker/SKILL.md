# 每日军情追踪器

这个 skill 的职责是：追踪**军事与地缘安全领域的每日大事**——武装冲突、军备与装备动向、军事演习、地缘博弈、防务政策与结盟——把散落各处的事实去重、归类，产出一份每条都带**事实、简短影响判断、一手来源链接**的结构化 Markdown 简报。

**它的定位是"帮你了解世界"。** 视角力求**全球均衡**：大国博弈与热点冲突并重，不偏向单一阵营的叙事。地缘政治与军事密不可分，所以直接影响安全格局的外交/结盟/制裁也收，但纯粹的经济制裁细节归财经简报，这里只记它的安全含义。

检索日期范围：默认昨天（日报）

## 覆盖范围

按下面几层组织，凡是落进这个圈的事件都收：

1. **武装冲突与热点**：正在进行的战争与冲突（战线变化、重大战果、停火/谈判）、突发军事对抗、边境摩擦、恐袭与反恐行动
2. **军备与装备**：新武器/新装备列装或试验（导弹、战机、舰艇、无人机、高超声速、核力量）、军售与技术转让、军费预算重大调整
3. **军事演习与部署**：大规模联合演习、兵力调动与前沿部署、基地新建/关闭、航母/战略核潜艇动向
4. **地缘博弈与结盟**：军事同盟动向（北约、上合、AUKUS 等）、防务条约、峰会中的安全议题、影响力争夺（非洲/中东/印太/北极）
5. **防务政策与战略**：各国国防白皮书/战略文件、军改与建军动向、太空军/网络战/无人化等新域动态
6. **风险与预警**：可能升级的紧张态势、核安全/扩散风险、重大情报披露（标注"据报道/待证实"）

## 工作流程

每次调用按四步走。**不要主动追问范围**——用户会自己说清楚；用户没说的部分用合理默认值直接执行。

### 第 1 步：分源检索

信息源完整地图见 `references/sources.md`，**每次都要读它**——它按"一手/权威通讯社 → 专业防务媒体 → 智库与开源情报(OSINT) → 官方源 → 中文源 → 检索技巧"分类，并标注每个源擅长抓什么和访问方式。

检索时遵循这些原则（前两条是硬性门槛）：

- **可信来源是入场券**：每条事件**必须**至少有一个可信来源——权威通讯社（路透/法新/美联/彭博）、专业防务媒体（Defense News、Janes、War Zone 等）、成熟 OSINT（ISW、Bellingcat、可信开源情报账号）、官方声明（国防部/军方/政府）。**单一社媒传闻、无出处的"网传"不入简报**，除非多源交叉且明确标注"待证实"。
- **多源交叉**：军事信息假消息与宣传极多。同一事件尽量有**两个立场不同的独立来源**再写入，交战双方各执一词时**双方说法都记**并标注出处，不选边站。
- **区分事实、宣称与预测**：己方战报、官方声明常有宣传成分——战果数字、伤亡数字一律标注"（X 方称，待独立核实）"。事实（发生了某事）与宣称（某方声称的结果）与分析（智库/媒体的推测）三者严格分开。
- **时间窗内**：只收用户指明时间窗口内的事件。默认昨日。拿不准时间时信任通讯社的报道时间戳，不信任模糊的"近日"。
- **并行检索**：内置 `search` 工具为主力（实测在 Cowork 环境最稳、召回新鲜中文效果好）；`WebSearch` 作备用（部分环境不可用，失败时不要重试，直接换 `search`）；有明确 URL 时用 `WebFetch` 抓详情；要看页面列表（如通讯社首页、ISW 每日更新）时用内置 `browser` navigate + snapshot。
- **检索式技巧**：英文用 `<冲突/地区> latest <date>`、`<武器名> deployed/tested`、`military exercise <country> <month>`；追热点用 `site:reuters.com <关键词>`、`site:understandingwar.org`；Google 时间范围限过去 24 小时/7 天。

### 第 2 步：综合去重

把检索到的零散信息合并：

- 同一事件多源 → 合并为一条，双方说法并记，标注一手出处
- 按覆盖范围的层归类
- 按"重要性 × 影响面 × 新鲜度"排序：可能改变战略格局的大事靠前，例行演习/小摩擦靠后
- 诚实标注：战果/伤亡数字标"某方称，待核实"；未证实的传闻标"据报道"，不要写成定论

### 第 3 步：保存 Markdown 简报

1. 保存路径
- 日报情况下（默认）：取`昨日日期`构建文件名 `军情简报-<日期>.md`
- 其他情况（多日）：`军情简报-<起始>_<结束>.md`（结束日期取昨日）
- 存到当前工作目录下的 `docs/00-每日简报/简报-军情/` 文件夹

2. 质量底线
- **每条至少一个可信来源**（通讯社/专业防务媒体/成熟 OSINT/官方声明）。单一社媒传闻、无出处"网传"不入简报，除非多源交叉且标"待证实"。
- **多源交叉、双方并记**。交战/对立方说法冲突时都记，不选边。战果与伤亡数字一律标"X 方称，待独立核实"。
- **区分事实/宣称/分析**。发生的事是事实，某方声称的结果是宣称，媒体智库的推测是分析——三者标清楚。
- **影响客观化**。只写"对局势的可能影响"，不预测胜负、不做站队式褒贬、不给任何行动建议。
- **不编造**。检索不到足够可信来源就如实说"本期可信来源有限"，不要为凑模板编造事件、数字或链接。
- **日期核对**。涉及"今天""昨日""最新"的表述，先用 Bash 获取当前系统时间核对，不信任媒体模糊的"近日"。

3. 简报模板

每个条目**必须**包含三要素：事实、简短影响、一个或多个来源链接。这是本 skill 的核心输出约定，务必照做。**影响写"客观可能影响"，不做买卖式建议、不做站队式褒贬。**
章节按覆盖范围的层分，**不是所有章节每期都要有**——本期哪层有大事就出哪节，没有就省掉，不要硬凑。但"一句话概览"通常都要有。上面的章节只是示例，实际按本期内容灵活命名和组合。

条目格式说明：
- **事实**回答"发生了什么、何时何地、涉及哪些方"——客观陈述，不带情绪。
- **各方说法**：交战/对立各方说法有冲突时并记，数字标宣称方。这是军情简报防假消息的关键。
- **影响**：本 skill 区别于纯新闻剪报的价值——用 1-2 句给"客观可能影响"，帮读者理解这件事为什么重要。**只写可能影响，不预测胜负、不站队、不做建议。**
- **来源**必须可信（通讯社/专业防务媒体/OSINT/官方）；单一社媒传闻不作主来源。

```markdown
# 每日军情简报 · <日期，如 2026-08-03>
```
