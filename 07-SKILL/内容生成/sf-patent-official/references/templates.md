# 技术交底书模板说明

模板文件位于本 skill 的 `assets/` 目录下。

> 来源：钉钉知识库「集团专利评审委员会 / 知识产权组 / 专利技术交底书模板」官方文件夹（更新于 06-26），2026-08-12 确认为法务官方版，共五类。

## 模板通用结构

所有模板共享相同的文档结构，由两个表格组成：

### 表格 1：联系人信息

| 字段 | 说明 |
|------|------|
| 技术联系人 | 发明人姓名（须与知识产权系统提案人一致） |
| 联系电话 | 手机号 |
| 归属部门 | 完整部门路径，如"顺丰科技技术集团/大数据平台研发中心/AI技术平台组" |
| 电子邮箱 | 公司邮箱 xxx@sf-express.com |

### 表格 2：详细技术信息（5 大章节）

| 章节 | 子节 | 内容 |
|------|------|------|
| 1、提案名称 | — | 一种+技术描述+方法/系统/装置 |
| 2、背景技术 | 2.1 现有技术介绍 | 技术领域、背景、现有方案描述 |
| | 2.2 现有技术缺点 | 要解决的技术问题 |
| 3、详细方案 | 3.1 核心发明点 | 2-4 个关键技术要素 |
| | 3.2 完整技术方案 | 详细描述（最核心部分） |
| | 3.3 技术效果 | 量化的技术优势 |
| 4、技术补充 | 4.1 替代方案 | 防绕开的其他实现方式 |
| | 4.2 术语说明 | 英文缩写和专有术语定义 |
| | 4.3 参考文献 | 相关专利/论文/网页 |
| 5、技术声明 | 5.1 实施情况 | 是否已在产品中使用（四选一） |
| | 5.2 公开情况 | 是否已对外公开 |

## 五种模板的差异

各模板仅在 **3.2 完整技术方案描述** 的示例和引导提示上有所不同：

### 算法模型类

3.2 引导结构：
1. **模型的介绍**：整体结构 → 各模块作用（附模型结构示意图）
2. **模型的训练方法**：训练数据集获取 → 数据预处理 → 损失函数（如有多个子模型分别描述）
3. **模型的使用**：应用场景、部署方式

### 应用软件类

3.2 引导结构：
1. **系统整体架构**：各模块/组件及其关系
2. **方法步骤**：用 S1、S2、S3... 步骤化描述具体流程
3. **关键模块详述**：每个步骤的具体实现

### 机械结构类

3.2 引导结构：
1. **整体结构**：各部件组成及位置关系（附结构示意图）
2. **各部件详述**：每个部件的功能和连接方式
3. **工作原理**：使用时的运动/传动过程

### 外观设计类

3.2 引导结构：
1. **产品六面视图**：正面/背面/左侧/右侧/顶部/底部
2. **立体图**：整体外观效果
3. **设计要素**：形状/图案/色彩等

### 通用模板

不限定具体描述结构，技术方案的表达形式可以自由安排。适合不属于上述四种类型的发明。

## 生成文档时的注意事项

1. **删除模板示例**：填入实际内容后，必须删除模板中的示例文字
2. **保留表格结构**：内容填入表格单元格中，不要破坏表格格式
3. **文件命名规范**：`专利技术交底书-{提案名称}-{YYYYMMDD}-v1.docx`
4. **附图必选**：使用 `scripts/draw_utils.py` 生成附图并插入文档，每份交底书至少2张图
5. **模板路径**：`assets/*.docx`（已内置于 skill 目录中）
