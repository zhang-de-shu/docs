# 阶段 11 — 渲染校验逐页核对指令

**结构校验 ≠ 视觉校验**：程序查样式全对，打开仍可能串行/图崩/豆腐块。装配完成后必须渲染回看。

## 渲染

用 `scripts/render_check.py`：docx → pdf（libreoffice/soffice）→ 逐页 png（pdftoppm）。
缺依赖时脚本报具体安装命令；未安装则降级：请用户在 Word/WPS 打开通览反馈，同时自己执行下面的结构自查。

## 逐页核对清单（逐页 Read png，逐项打勾）

**整体**
- [ ] 两个表格齐全：联系人表 + 详细技术信息表
- [ ] 五大章节都在：背景技术 / 详细方案 / 技术补充 / 技术声明（按模板结构）
- [ ] 模板自带的示例文字已全部清除（搜索"示例""待填写"等残留）

**联系人表**
- [ ] 姓名/电话/部门/邮箱四项完整，无占位符

**正文**
- [ ] 章节标题层级正确，无正文被渲染成标题
- [ ] 中文无豆腐块 □
- [ ] 表格单元格内容无截断、无串到相邻单元格

**附图**
- [ ] 所有（附图N）标记处都已嵌图，数量与清单一致（≥2 张）
- [ ] 图清晰、不越界、宽度不超出版心
- [ ] 图与图注对应，无孤儿图（嵌了但正文没提）

**分页**
- [ ] 无标题孤行（标题在页底、内容在下页）
- [ ] 图未被分页截断

## 处理

任一不合格 → 定位是内容问题（改内容）还是装配问题（改 fill_template 调用参数）→ 修复后重新装配、重新渲染，直到全部通过。
