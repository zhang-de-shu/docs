# 阶段 12 — 五维质量评审引导话术

以代理师/审查员视角逐维自问，**每维给出明确结论**（通过 / 有风险+理由 / 不通过+修改建议），汇总进自检报告。框架与判定标准见 references/review-guide.md。

## 逐维自问

**① 新颖性**
- 核心方案与阶段 6 对比文件的最小区别点说清了吗？
- 2.1 是否具体指出了最接近现有技术（而非泛泛而谈）？

**② 创造性（核心，权重最高）**
- 区别点是否"非显而易见"？阶段 7 的五角度论证命中了几条？
- 四类反模式（事后诸葛/纯参数调整/简单叠加/等价替换）排查了吗，有命中吗？
- 结论偏弱 → 回阶段 7 补充追问用户。

**③ 保护范围**
- 主发明点表述是否过窄（写死具体实现，易被绕开）？
- 是否过宽（把现有技术也圈进来，易被驳回）？
- 建议：主发明点用上位表述，具体参数/实现放替代方案或实施例。

**④ 单一性**
- 是否把多个互相独立的发明塞进一份交底书？（判断标准：它们是否共享同一个发明构思）
- 是 → 建议用户拆分为多篇提案，本篇保留主线。

**⑤ 可实施性**
- 技术小白照 3.2 能否复现？关键步骤有无缺失（如数据从哪来、模型怎么训练、异常怎么处理）？
- 术语是否全部解释、前后一致（term_consistency 结果）？

## 输出格式

```
五维评审结论：
① 新颖性：通过/有风险——……
② 创造性：……（五角度命中 N 条）
③ 保护范围：……
④ 单一性：……
⑤ 可实施性：……
总体：可交付 / 需返工（返工项：……）
```

总体为"需返工" → 回到对应阶段修改后重审。
