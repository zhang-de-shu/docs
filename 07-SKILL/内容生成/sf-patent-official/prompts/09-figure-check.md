# 阶段 9 — 附图生成 + 逐图自检指令

## 绘图流程

1. 从 3.2 的（附图N）标记生成绘图清单；对照 references/figures-guide.md 的必选附图表查缺（**每份至少 2 张**）。
2. 用 `scripts/draw_utils.py` 绘制：`setup_cjk()` 后调高层函数（`vflow`/`vmodules`/`draw_tree`/`draw_sequence`/`draw_data_flow`/`draw_component_callout`/`draw_six_views`，各自带画布并保存），或用低层图元自由拼装。
3. 风格六硬规则：白底·纯黑·粗线（lw≥1.8）·框随文字自适应·单列竖排·画布 6.4in 字够大。详见 figures-guide.md。

## ⚠️ 逐图自检（每画完一张必做，不可跳过）

**每张 PNG 画完立即 Read 回看**，逐条核对：

- [ ] 纯黑粗线白底，无彩色/发灰
- [ ] 文字在框内、四周留白，无溢出贴边
- [ ] 单列竖排，线不穿框
- [ ] 无文字压线；无竖排单字标签
- [ ] 线条/文字完整，无被切被吞；无缺字/乱码/豆腐块 □（有中文 → 确认 CJK 字体已生效）
- [ ] 字够大（嵌入 Word 后与正文相当）；图内术语与正文术语表一致
- [ ] 图文匹配：画的就是（附图N）描述的内容

任一不合格 → 修改重画，直到通过。这是"稳定出好图"的关键，跳过必出溢出/压线/小字。

## 失败降级

- 单张图反复重画仍失败 → 保留绘图源码与文字描述，标注「待补图」，继续后续流程；交付前提醒用户。
- 外观设计类：六面视图等素材由用户提供照片/设计稿，skill 只做排版与标注，不代画外观。

## 嵌入

标记与绘图清单一一对应是本阶段职责；实际嵌入在**阶段 10 统一执行 `embed_figures()`**（强制校验，缺标记/缺图即报错中断，见 prompts/10-assembly.md）。本阶段不直接操作 docx。
