# 阶段 7 — 区别论证 / 创造性话术与指令

创造性是授权核心门槛。同样技术，讲得好能过、讲得差被驳。本阶段把"区别点 + 为何非显而易见"结构化讲清楚。

## 追问话术（逐个发明点问，一次问全）

> 针对发明点 ①，需要你的判断（这些只有发明人清楚）：
> 1. **最接近的方案**——在做之前，业内/公司内部最接近的做法是什么？
> 2. **最小区别**——本方案与它相比，最小的区别是什么？
> 3. **能否轻易想到**——这个区别，本领域技术人员看到问题后能轻易想到吗？为什么不能？
> 4. **为何没人做**——之前为什么没人这么做？（没想到 / 有障碍 / 有偏见 / 没必要）

对比文件已由 `scripts/parse_prior_art.py` 抽出摘要/独立权利要求/特征短语，供特征对照。

## 五角度论证引导（命中越多越好，写入 3.2/3.3）

对照用户的回答，从五个角度挖掘并成文：

1. **克服技术偏见**——业内认为不可行，本发明反而做成
2. **解决长期未解难题**——问题存在多年一直无好解
3. **预料不到的效果**——质变而非叠加（提升 10 倍 ≠ 提升 10%）
4. **非常规组合**——本不相关的 X 与 Y 结合产生新作用
5. **说清别人为何没做**——解释此前无人如此做的原因

## 四类反模式自查（撰写时逐条排查）

- **事后诸葛**：用"显而易见"倒推，实际当时无人做出 → 补"为何没人做"
- **纯参数调整**：只是调了阈值/权重 → 必须说明参数确定方法本身的创新，否则删该点
- **简单叠加**：A 功能 + B 功能拼一起，各自独立工作 → 须论证组合产生新作用
- **已知等价替换**：换成业内公知的等价手段 → 删该点或降级为从属内容

## 对齐审查三步法（写法对照）

| 审查三步法 | 交底书写法 |
|-----------|-----------|
| ① 确定最接近现有技术 | 2.1 具体指出（引用阶段 6 确认的对比文件） |
| ② 找区别特征、定实际解决的问题 | 3.1 发明点 = 与最接近现有技术的区别 |
| ③ 判断是否显而易见 | 3.2/3.3 中五角度论证 |

## 边界

skill 无法替代代理师判定"有无创造性"（需全球检索）；skill 的职责是把区别与非显而易见性**充分呈现**。评审结论见阶段 12。
