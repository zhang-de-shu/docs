# 阶段 16 — 命名 / 交付 / 提交指引

## 命名规范

`专利技术交底书-{提案名称}-{YYYYMMDD}-vN.docx`

- 提案名称即 G1 确认的提案名（「一种XXX方法/系统/装置」）。
- 日期为交付日；版本号从 v1 起，迭代递增（见 prompts/17-iteration.md）。

## 交付话术

> 终稿已确认，交付如下：
> 1. **终稿**：专利技术交底书-……-vN.docx
> 2. **自检报告**：五维评审结论 / 格式自查 / 保密扫描处置 / 数字核验结果
> 3. **修订与审计记录**：含 G1/G2 确认记录（请一并保存，法务可能调阅）
> 4. **申请指引**：见下
>
> 后续提交请按 references/patent-guide.md 操作：登录知识产权系统 → 新建提案 → 按字段规范填写（提案人须与技术联系人一致）→ 上传交底书 → 提交。从提案到受理约 2–4 个月，建议尽早提交。

```
## 格式自查
附图 N 张（≥2 ✓）；术语一致性：…；缩写全部解释：✓/✗ …

## 事实核验（阶段 13）

## 保密自检（阶段 14）
告警 N 条，处置：删除 x / 脱敏 x / 批注待法务评估 x。

（待补图 / 待法务评估项 / 其他）
```
