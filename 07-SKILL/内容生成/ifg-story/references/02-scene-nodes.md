# 阶段二：节点及分支拆解

## 工作步骤
- 字段说明见：data-model.md
- 阶段一的产出在project.json, 据此完善project.json中属于阶段二的字段（`chapters`、`nodes`、 `scenes`）
- 任务包括：节点设计、BE设计、选项设计、结局设计

## 规则
- 节点
    - 节点数：序章5-10 个节点；正章20-40个节点
    - 全部非 ending 节点必须有玩家选项；explore 节点须有 `exploreReturnNodeId`。
    - branch 节点 → 2-3 条路径专属场景 → merge 汇回主线。 （merge 后的开场台词按玩家来路差异化）
    - 全片 branch 节点占比 ≥25%；每章 ≥1 个中段分支；改变后续路径的剧情分岔节点是稀缺资源，每章 1-3 个。
    - **节点类型学（混合使用，禁止全是对话分支）**：①剧情分岔节点（改路径）②性格测验节点（即死 BE 岔口）③状态写入节点（不改路径但写 Flag/好感度，后果延迟回响）④计时压迫节点（限时选择，超时视为一种选择，全剧 0-3 个）⑤微互动节点（点击/上滑/拖拽等非分支交互，维持参与感不打断节奏，全剧 0-3 个）⑥回响读取节点（专门"兑现"此前 Flag 的场景：某角色提起你上一章做过的事、某道具因早前选择而出现/缺席——每个核心 Flag 至少对应 1 个）。
    - **章间收束**：每章末尾回到共同事件（瓶颈）进入下一章；上一章的差异通过**变量 + 内容裁剪**（某些小节因之前的选择而出现/缺席/变化）延续，不做章间真分岔。
- 结局
    - 一章仅最多输出1-3个结局，更多的结局需要平行章节（从同一个章节延续而来的章节）各自产出
    - **最长结局路线。** 全剧最多一个"最难结局"，路线最长，从分叉点起可再跨越 1-3 个整章才收束，沿途积累该结局专属的 Flag/好感/凭证。TE 通常走此形态。
    - 同一章内产出的结局，通常需要放在不同的分支；仅当差异很小的结局允许使用门控扇出
    - **禁止终章单点扇出**：多个结局节点的直接前置是同一个选择节点即违规；每个结局节点之前必须有 ≥1 个**只属于该结局路线的专属小节**（此路线上玩家才能看到的场景/对白/情感时刻）——"门控看资格，路线给内容，结局是路径的自然终点"。
    - 未满足条件的结局路线对玩家**不可见或不可选**（不是选了才知道走不通）；门控扇出（例外形态）同样须每结局 ≥1 专属前置场景。
- BE 选项
    - 即死 BE数：序章2-5；正章5-10个（按间隔散布全章）
    - 部分节点只有一个能存活的选项、其他选项都走向 BE
    - **即死不等于真死**：BE 的本质是"选择导致故事提前终结"——主角身死只是形式之一，暴露/败露/任务失败/关系崩塌/被驱逐等命运性恶果同样成立；但恶果必须呼应主角 fatalFlaw（性格测验，非随机惩罚）。
    - 好感度心碎（清零）可触发角色中途 BE——把"负积累"也变成内容。
    - BE选项文案零危险预警。禁止杀/抢/撕/翻/硬闯/独吞/怒/赌命等风险词；BE 选项与安全选项一样中性、甚至更诱人（更快的捷径、更符合直觉的解决、更有诱惑力的方案）
    - 事前线索（叮嘱/忠告/前车之鉴）可选埋、鼓励埋：埋了是"观察力测验"，不埋时因果链也须自洽
    - 死因必须由选项所代表的行动在当下情境中**必然触发**。consequence 须一句话说清"死亡机制链"：这个动作 → 触发情境中已存在的危险；BE 节点 narrative 必须把因果链演出来（动作→危险反应）
    - BE 分支标记 `isDeadEndBE: true`
    - BE 选项**不写** variableEffects
- 普通选项
    - normal 推进节点：2-3 个真选择（同目标、不同语气/变量效果）；禁止"继续"式单选项。
    - **无后果不成选择**：每个选项至少命中一类后果——即死 BE / 变量·好感度·Flag 变化 / 台词与场景差异 / 延迟回响 / 主角信息获取；每个互动点必须回答"为什么是这里"和"选完之后怎样"。选了跟没选一样，就是装饰不是选择。
    - **每个选择点四问校验**：①玩家为什么必须选（动机）②选完状态变了吗（变化）③后续剧情承认这个选择吗（承认）④不同状态组合能自然导向不同结局吗（回路）。
    - 菱形分支各路径：写 variableEffects；分岔并回后必须留下变量/Flag 痕迹并在后续对白/选项中回响（哪怕主线不变）。
    - 路线门控：用结局 keyVariable（阈值取 0-10 量表中的 3-6）。
    - **软门控优于硬门槛**：好感/Flag 不足时关闭的是"可得内容"（隐藏剧情、支线、专属结局路线），不要卡主线进度。
    - 带条件选项的节点：必须有无条件保底出口。
- 场
    - 场的 location/time/在场人物骨架随场记录写入
    - 划场依据：地点变 / 时间流逝 / 人物进出 / 道具状态变
    - 在场记录上标记每个角色的**首次出场节点**（firstAppearance）
- 支线
    - 每章 1-2 条可选支线（各 2-5 小节），提供主线之外的自我表达；可跳过、不卡主线。
    - 支线短小凑数比没有支线更糟。
