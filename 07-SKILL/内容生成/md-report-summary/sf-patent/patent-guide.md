# 顺丰集团专利申请指南

## 一、提交前准备

### 1. 技术交底书 💡 撰写思路

**技术问题 → 技术方案 → 技术效果**

**核心内容：**

* 提案名称
* 背景技术（现有技术及其缺点、本发明解决的技术问题）
* 详细方案（核心发明点、完整技术方案描述、技术效果）
* 技术声明（本发明在业务层面的实施情况）

**模板下载：**
https://fsdocs.sf-express.com/desktop/mydoc/folder/AJANDDXFEQWyLmvoQY

---

### 2. 检索优化

为了进一步了解现有专利技术情况、优化专利方案，公司提供商业数据库供查阅学习。

## 二、系统操作流程

### Step 1 登录入口

知识产权管理系统：
http://iprs.sf-express.com/index.html#/admin

### Step 2 新建申请

### Step 3 关键字段填写规范

| 字段        | 填写提示                      |
| --------- | ------------------------- |
| 拟申请专利类型   | 分为：发明专利 / 实用新型专利 / 外观设计专利 |
| 发明专利      | 保护产品、方法或改进；需具备新颖性、创造性、实用性 |
| 实用新型专利    | 保护产品结构、形状等改进              |
| 外观设计专利    | 保护外观设计（形状、图案等）            |
| 不授予情形     | 科学发现、智力活动规则、平面图案等         |
| 发明人       | 按实际贡献填写，不可为0              |
| 项目代码/系统编码 | 必填，无则填“无”                 |

> 最终申请类型由专利法务复核确认

---

### Step 4 附件上传

**必需文件：**

* 技术交底书（Word）
* 附图（CAD / SolidWorks 等可补充）

## 四、重要注意事项

### 1. 保密要求

* 不得包含未公开源代码 / 实验数据（需脱敏）
* 专利申请前不得对外公开技术

### 2. 时效性

* 从提案到受理约 **2–4个月**
* 建议提前 **3个月提交**
* 紧急情况需提前与法务沟通
