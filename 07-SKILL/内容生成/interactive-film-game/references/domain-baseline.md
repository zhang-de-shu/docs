# 领域基准：互动影游

本文件是结构生成、校验标准与体验设计的**领域依据**。结构/选项设计中的核心机制参数必须能指回本文档的具体条目。

**产品定位：按互动游戏（AVG / 视觉小说 / 互动电影游戏）标准设计的轻量作品**。对标的是隐形守护者、完蛋、直到黎明这一类的**结构与互动密度**，但规模取其小一档——它们是 10 章/6 章的大作，本 skill 产出 **5 章左右的轻量版**。核心立场：**互动密度不打折，只砍总量**；但单章体量轻不等于故事压扁——全剧必须横跨一个较长的故事时间跨度（数月乃至数年），每章是跨度内的一个或多个时间点，章与章之间要有可见的时间流逝与后果累积（人物成长、关系变迁、世界变化），而不是同一周内挤完的一场风波。它是"游戏"而不是"可点击的短剧"——选择肢、Flag、好感度、BE/TE 结局阶层这些游戏机制一个都不能少。

## 1. 目标形态配方（生成时的第一约束）

结构范式：**Gauntlet × Branch & Bottleneck 叠加**——主干用分支-瓶颈承载状态成长，沿途用即死岔口制造张力与重玩，终章用状态门控扇出结局。逐条如下（量化数字见第 2 节，细则见第 3/4 节）：

- 主线细长，岔口通向死亡/短暂绕行（Gauntlet 窄主线）
- 大量即死分支，BE 是性格测验而非随机惩罚（§2.1/守则 3）
- 状态记忆贯穿全剧：分岔并回后用变量/好感度/Flag 留痕，关键 Flag 跨章延迟回响（§2.4）
- 少部分分叉通向不同结局，按 BE/NE/HE/TE 阶层组织，终章变量门控扇出（§3）
- 章是叙事单元，小节（一个场景+一个选择）是最小生成颗粒（§2.2）
- 支线任务提供"主线之外的自我表达"，是世界活着的证据
- 设计口诀：**游戏（让玩家做）> 展示 > 讲述**，顺序不可倒


## 2. 轻量互动影游结构量化基准

### 2.1 骨架数字（生成时的直接定标）

| 维度 | 基准值 | 
|------|--------|
| 章数 | **5 章左右**（4-6 章可接受）；全部章节覆盖一个**完整的故事时间跨度**（数月乃至数年），每章是跨度内一个或多个时间点的故事 |
| 序章 | **必有**：正文前独立序章，约 10-15 节点，承担背景交代 + 玩法教学（首次选择/变量感知/即死 BE 示范），不计入正文章数 |
| 每章小节数 | **20-30 小节**（含 BE 小节；下限对标完蛋两倍密度，上限不超底特律大章） |
| 单小节时长 | 30 秒-2 分钟（约 100-400 字脚本 / 2-6 个画面） |
| 全流程 | 30-90 分钟单路径；素材总量 ≤ 放映路径 3-5 倍 |
| 选择密度 | **每个非结局小节 ≥1 个真选择；normal 推进节点须 2-3 个真选择**（同目标不同语气/变量效果）；高压章可加密至每节点含计时/微互动 |
| 每节点选项数 | 2-4 个（2-3 为主流） |
| 即死 BE 岔口 | **每章 4-8 个**（占选择节点 20-30%，全剧 20-40 个） |
| 状态变量/Flag 数 | **3-6 个核心变量**（路线/立场 1-2 + 剧情Flag 全剧 1-3 + 题材变量 0-2：好感度/存活状态/怀疑度视题材启用） |
| 结局阶层 | **BE 若干（中段）+ NE 1-2 + HE 2-4 + TE 1** |
| 支线 | 每章 1-2 条（2-5 小节，可跳过不卡主线） |

### 2.2 章 / 场 / 小节的职责划分

- **章 = 叙事单元 = 时间跨度内的一个或多个时间点**：一条完整剧情弧，开场即冲突（承接上章钩子）→ 章内分岔与瓶颈收束 + 4-8 个即死岔口 → 章末高潮 + 强钩子；章首需交代距上章的时间流逝（章名/开场即可感知）。
- **场（scene）= 时空单元**：一段连续时空（同一地点 + 时间流），覆盖 1-N 个连续节点；背景、道具状态、在场人物定义在场上，节点引用 sceneId。每章 4-8 场；划场依据：地点变 / 时间流逝 / 人物进出 / 道具状态变。阶段二分幕划场，阶段三充实环境。
- **小节 = 互动单元**：一拍完整的故事时刻（进入状态 → 冲突 → 离场变化）+ 一个选择（或一个 BE/收束点）。小节是最小生成与校验颗粒；超长小节必须拆分。
- **章间收束规则**：每章末尾回到共同事件（瓶颈）进入下一章；上一章的差异通过**变量 + 内容裁剪**（某些小节因之前的选择而出现/缺席/变化）延续，不做章间真分岔——底特律工程手段，轻量影游控成本的唯一可行路径。
- **章名可随状态变化**（直到黎明手法）：低成本高感知的"世界记得你的选择"信号。

### 2.3 节点类型学（生成时应混合使用，禁止全是对话分支）

1. **剧情分岔节点**——改变后续路径（稀缺资源，每章 1-3 个）
2. **性格测验节点（即死 BE 岔口）**——错误选项直达 BAD END：**这条路线的故事到此为止**（主角的真死只是形式之一——暴露、任务失败、关系崩塌、被驱逐等"命运性恶果"同样成立），恶果呼应主角弱点（每章 4-8 个，占选择节点 20-30%）
3. **状态写入节点（Flag/好感度）**——不改路径但写变量，后果延迟回响（部分适合的章节采纳，flag 不能太多，全剧 1-3 个，好感度视题材采纳）
4. **计时压迫节点**——限时选择，默认超时视为一种选择（全剧0-3个）
5. **微互动节点**——点击/上滑/拖拽等非分支交互，维持参与感不打断节奏（全剧0-3个）
6. **回响读取节点**——专门"兑现"此前 Flag 的场景（某角色提起你上一章做过的事、某道具因早前选择而出现/缺席），是延迟回响的显性载体；每个核心 Flag 至少对应 1 个

好感度刻度建议沿用完蛋的四级制：**少量 / 常规 / 大量 / 巨量**（及对应的减值、清零=心碎），让数值差异玩家可感知。

### 2.4 状态与 Flag 设计（互动游戏与短剧的分界线）

互动游戏与"可点击短剧"的分界线是状态系统。先定骨架，再定状态表，最后生成内容：

- **变量类型**：角色状态变量（受伤/黑化/被通缉…）+ 关系状态变量（谁信任你/谁怀疑你/谁被你救）+ 路线变量（累积的阵营/立场标记，终章裁决用）+ **剧情 Flag**（布尔型：看过某事件/拿到某证物/说过某话——galgame 标准机制，成本低、回响手法最丰富）
- **每个选择点四问校验**：①玩家为什么必须选（动机）？②选完状态变了吗（变化）？③后续剧情承认这个选择吗（承认）？④不同状态组合能自然导向不同结局吗（回路）？——选了跟没选一样，就是装饰不是选择
- **延迟回响的最小要求**：变量写入后 ≥1 个后续节点读取；核心变量至少跨 1 章回响（完蛋标准：第 2 章的选择在第 5 章开花）；蝴蝶效应式回响（直到黎明标准：看似无关的小选择在终盘重构为陷阱）至少设计 1-2 处
- **软门控优于硬门槛**：好感/Flag 不足时关闭的是"可得内容"（隐藏剧情、支线、专属结局路线），不要卡主线进度（完蛋的差评教训）
- 好感度心碎（清零）可触发角色中途 BE——这是把"负积累"也变成内容的手法
- **TE（真结局）设计**：TE 不是第 N 个并列结局，而是**回收全部伏笔与世界观的最终答案**，达成都需要跨周目或高门槛 Flag 组合（galgame 多周目标准）——轻量版至少要求：TE 路线读取 ≥3 个分散在全剧的 Flag/好感阈值，让"看遍所有结局"自然衔接"理解整个故事"

## 3. 结局分布守则

**禁止把全部结局堆在同一个场景之后**（最后一个节点放 3 个选项、每个选项直通一个结局）。判定规则：若多个结局节点的直接前置是**同一个**选择节点，即为违规；每个结局节点之前必须存在至少一个只属于该结局路线的专属小节。

**正确做法（生成与校验双重约束）**：
- 终章结构 = 高潮 → **变量门控**（conditions 读取全程累积的路线变量/好感度/Flag，只开放玩家"挣来的"结局路线）→ 每条路线先有 **≥1 个专属内容小节**（此路线上玩家才能看到的场景/对白/情感时刻）→ 结局节点。即"门控看资格，路线给内容，结局是路径的自然终点"。
- 未满足条件的结局路线**对玩家不可见或不可选**（不是选了才知道走不通）。
- 结局数量与路线专属内容量必须匹配：**每个主结局 ≥1 个专属前置小节**（结局数量是虚荣指标，内容支撑才是体验）；进阶形态是**每个主结局一条专属终章路线**（隐形守护者末章分线模式）——5 章轻量版章数有限，默认按"专属小节"执行，仅当结局数 ≤ 章内可容纳路线数时升级为专属章。
- 用 **BE/NE/HE/TE 阶层**组织结局：中段 BE 是密度型内容不占结局预算；终章至少产出 2-4 个 HE/NE 差异路线 + 1 个高门槛 TE。
- 参考完蛋的进阶手法：隐藏结局绑定好感极值（心碎 BE / 拉满直通专属篇），让二周目"号脉式重玩"有价值。

## 4. 体验守则

1. **选择频率**：每个非结局小节 ≥1 个真选择；normal 推进节点须 2-3 个真选择（同目标不同语气/变量效果），禁止"继续"式单选项
2. **无后果不成选择**：每个选项至少命中一类后果——即死 BE / 变量·好感度·Flag 变化 / 台词与场景差异 / 延迟回响 / 主角信息获取。；每个互动点必须回答"为什么是这里"和"选完之后怎样"
3. **即死 BE 是一等内容**：每章 4-8 个通向 BAD END 的岔口（占选择节点 20-30%）。**即死不等于真死**——BE 的本质是"选择导致故事提前终结"，主角身死只是形式之一，暴露/败露/任务失败/关系崩塌/被驱逐等命运性恶果同样成立，但必须呼应主角弱点（性格测验，非随机惩罚）；BE 有专属场景，不是黑屏（428：BE 是流程的一部分）
4. **状态记忆与延迟回响**：分岔并回后必须留下变量/Flag 痕迹，并在后续对白/选项中回响（哪怕主线不变）；关键 Flag 跨章兑现，至少 1-2 处蝴蝶效应式远期回响。反面教材：盛世天下好感度系统对剧情无影响
5. **回溯即玩法**：BE 后回到最近选择点重试是核心循环（428 的流程图回溯、商业形态中的付费点）
6. **章节流程图可见**：结构图是重玩驱动力，未点亮路径应可视
7. **节奏钩子**：每章末=强钩子，每小节开场即冲突
8. **结局分布**：见第 3 节，禁止终章单点扇出（多个结局共享同一前置选择节点即违规）
9. **支线即世界**：每章 1-2 条可选支线，提供主线之外的自我表达；支线短小凑数比没有支线更糟
10. **游戏 > 展示 > 讲述**：优先让玩家做，其次展示，最后才是讲述
