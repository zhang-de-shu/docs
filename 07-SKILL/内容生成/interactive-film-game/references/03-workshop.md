# 阶段三：场景工坊（workshop）

对结构阶段产出的每个节点做逐节点精修：情感弧填充 → 对白创作 → 对白诊断/修订 → 选项精修。开始前确认阶段二结构已定稿。

## 完成标准

- 全部非 ending 节点有情感弧（emotionFunction 六字段）与 6-10 行对白（不少于 6 行）。
- 每个场景 sceneDesc 为摄影机语言（只写可见的动作与空间细节）；带条件选项的节点均有无条件保底出口。
- BE 节点对白短而有戏、有专属画面感；即死不等于真死——BE 是"故事到此为止"（暴露/失败/崩塌/被逐/身死皆可），恶果呼应主角 fatalFlaw 弱点（性格测验，不是随机惩罚）。
- 回响读取节点必须有：某角色/道具/信息因早前 Flag 而出现、缺席或变化的对白体现（状态记忆的可感知兑现）。

## 工作步骤

1. **情感弧填充（workshop:fill_emotion）**：为每个节点设计深层情感状态。
    - 情感设计原则：
        - 角色的外部行为与内心状态必须存在张力：一个"平静"的人内心可能是"恐惧"，一个"愤怒"的人内心可能是"绝望"。
        - internal_lie：此刻角色正在对自己撒的谎，用来保护自己不面对真相（例："只要我不说出来就不算真的发生"）。
        - fear：此刻角色最想回避的事——不是具体危险，而是心理层面的恐惧（例：害怕被看穿自己一无所有）。
        - emotionIn/emotionOut 描述可见的外在情绪（进入和离开节点时），emotionOut 必须与 emotionIn 有明显变化或深化；playerEmotion 描述希望玩家产生的情感共鸣；tension 为 0-10 整数（结合戏剧节拍和情节位置判断）。
    - 输出模版：{"emotionIn":"表面平静，实则如履薄冰","emotionOut":"震惊与麻木同时涌上","playerEmotion":"强烈代入感，替角色捏一把汗","tension":7,"internal_lie":"他告诉自己这只是误会，很快会过去","fear":"被最信任的人看穿真实面目"}

2. **对白创作（workshop:write_dialogue）**：为每个节点写 6-10 行对白。对白必须从角色的四维心理模型（wound/lie/want/need）与声纹卡生长出来：
    - 四维驱动规则：每句台词由 WOUND 决定防御姿态、LIE 决定盲点、WANT 决定当下行动、NEED 决定他不愿承认的真相；禁止让角色说出超越其 LIE 认知范围的话；WOUND 决定角色如何用语言保护自己（攻击/逃避/讨好）。
    - McKee 对白核心法则（每条都是铁律）：
        1. 对白即行动，不是信息传递：每句话都是战术行为（攻击、转移、诱惑、控制、逃避）；禁止角色说出他们真正想说的话——人物永远通过迂回达到目的；每行对白后追问"他说这句话是为了对另一个人做什么？"
        2. 权力动态——场景的骨架：开场明确谁有权力；权力必须在场景中至少转移一次，且转移必须通过具体的一句台词实现；最后一行权力归属必须与开场不同，或悬而未决。
        3. 矛盾原则：每个场景至少有一个角色说出与自己真实想法相反的话，且对另一角色（和玩家）显而易见。
        4. 声音指纹——两个角色绝不能有相同的说话节奏：权威/控制型短句祈使、用停顿施压；内疚/压抑型从句堆叠、主动解释不必要细节、用"其实""只是"软化；戒备/聪明型反问、答非所问；破碎/受伤型句子中途停顿、否定自己刚说的、用"没什么"结束情绪爆发。
        5. 冰山定律——表面对话是 90% 藏在水下的战争：禁止角色直接陈述情绪（"我很害怕"→错误）；情绪通过行为细节体现（"他把合同翻到最后一页，又翻回第一页"→正确）；台词必须携带反差信息。
        6. 节奏法则——长短句交替：禁止连续 3 句以上相近句长；积累阶段用长句，爆发或权力转移时用短句（5 字以内）；关键转折后必须接一个短句或沉默动作。
        7. 场景节奏——压缩·扩展·悬停：开场压缩时间快速建立位置和目的（1-2 行）；中段在情绪高点扩展，让每句有重量（3-6 行）；收尾留在未解决的情绪时刻，不给完整答案。
        8. 禁用清单（违反即重写）：禁止"你好/最近怎么样/我明白"等填充台词；禁止自我介绍式说明背景；禁止连续两行对白没有任何情势变化；禁止最后一行给出情感闭合（结尾必须留钩）。
        9. sceneDesc 镜头语言——只写摄影机能拍到的：禁止"气氛紧张""她感到害怕"；必须包含一个能揭示权力关系的空间细节 + 一个角色的微小身体动作。
    - 对白必须为该节点后续的玩家选项积蓄张力：对白结束时，玩家必须感受到选择每个选项都意味着失去某些东西。
    - 输出模版：{"sceneDesc":"摄影机语言，2-3句，只写可见的具体动作和空间细节，揭示权力关系","dialogue":[{"speaker":"角色完整中文名","text":"说出口的台词——是战术行为，不是真实想法","emotion":"外在情绪状态，1-2个词"}]}

3. **对白诊断（workshop:scene_analysis，按需）**：像 McKee 审稿一样逐行批注。
    - 分析框架：找真正有效的部分（working：动作性对白/潜台词/权力动态/声音差异化哪里做得好）；最多 3 个问题按严重度排序（on-the-nose 说出真实想法 / throat-clearing 开场填充 / 权力平板整场无转移 / 声音趋同 / 情感直给 / 无钩收尾），每个问题给出具体重写台词；killer_line 一句能改变场景能量的建议台词（含说话者、台词、建议插入位置）。
    - 对白少于 3 行时：working 写"对白内容不足，无法完整分析"，issues 空数组，killer_line 给一句开场建议。
    - 输出模版：{"working":"…","issues":[{"line":"有问题的原始台词（引用原文）","problem":"问题类型和具体原因","fix":"具体的重写建议，给出修改后的台词"}],"killer_line":"一句能改变场景能量的建议台词——包含说话者和台词内容，以及建议插在第几行之后"}

4. **张力诊断（workshop:scene_tension，按需）**：对张力不足的场景做结构性诊断。
    - 诊断框架（按序）：tension_diagnosis（张力来源：外部冲突/内部撕裂/信息不对等/什么都没有）；missing_element（四大戏剧引擎——冲突/悬念/反转/代价——哪个最缺失）；rewrite_suggestion（≥100 字的具体建议：这个场景应该发生什么、加什么台词、删什么、节奏怎么调）；upgraded_line（一句立刻提升张力的台词，必须包含潜台词，格式"[说话人]：'台词'"）；mcguffin（驱动角色欲望的具体对象/信息/目标——没有 MacGuffin 是张力为零的根本原因）；dramatic_irony（是否存在玩家知道而角色不知道的反讽，如何放大或如何引入）。
    - 输出模版：{"tension_diagnosis":"…","missing_element":"…","rewrite_suggestion":"至少100字的具体重写建议","upgraded_line":"说话人：'台词'","mcguffin":"…","dramatic_irony":"…"}

5. **对白修订（workshop:revise_dialogue，按需）**：按诊断批注或用户一句话指令重写第二稿。
    - 修订铁律（违者无效）：最终对白 ≥6 行（不足则扩写）；每行是战术行为，禁止直陈情绪和背景；权力至少转移一次；至少一个角色说反话；两个角色节奏和用词可区分；最后一行不留情感闭合；sceneDesc 只写摄影机可见内容，不少于 80 字符。
    - 用户修改指令为最高优先级，必须遵照执行；编辑批注逐条解决。
    - 输出模版与 write_dialogue 完全相同。

6. **选项建议（workshop:suggest_choices，按需）**：为选择点设计道德复杂的选项。
    - McKee 的"差距"（Gap）原则：每个选项必须在玩家预期与实际结果之间制造差距——玩家以为选 A 得到 X，实际得到与 X 相关却截然不同的 Y；差距越大戏剧价值越高，但必须符合故事逻辑，不能随机惩罚。
    - 道德复杂性——禁止"正确答案"：禁止一个明显"正确"一个明显"错误"；每个选项代表不同价值观立场（忠诚 vs 真相、安全 vs 尊严、个人 vs 集体）；玩家选任何一个都应感到"我可能错了"。
    - **每个选项至少命中一类后果**：即死 BE / 变量·好感度·Flag 变化 / 台词与场景差异 / 延迟回响 / 主角信息获取——选了跟没选一样就是装饰不是选择。
    - **BE 选项文案原则**：有吸引力/危险诱惑、不能一眼看出死路，选中即终结这条路线，不写 variableEffects。
    - 字段要求：dramatic_cost 是情感/关系/自我认知上的代价（"失去某种自我"，不是失去物品）；thematic_resonance 必须具体（不是"体现了主题"，而是"玩家亲历了'[主题核心问题]'"）；text ≤10 字；consequence 立即情节，longterm 对后续章节的影响。
    - 输出模版：{"choices":[{"text":"追问真相","consequence":"对方崩溃，说出了连他自己都没准备好说的话","longterm":"获得真相但永久破坏了这段关系","dramatic_cost":"你用真相换取了一段友谊","thematic_resonance":"玩家亲历了'知道真相是否总是值得的'这一主题核心问题"}]}

7. **选项涟漪分析（workshop:choice_consequence，按需）**：推演单个选择的全链路影响。
    - 六维分析：immediate（进入下一场景最显著的变化）；chapter_impact（本章内累积影响：信任度、信息可见性、路径开闭）；ending_probability（结局概率，+/- 百分比描述）；character_cost（心理/关系代价，与 WOUND 和 LIE 共鸣）；thematic_resonance（玩家亲历主题的哪个层面：印证/挑战/揭示悖论）；regret_factor（后悔系数，只能是"高/中/低"）+ regret_reason（好的设计让玩家后悔，但理解为什么当时选了它）。
    - 输出模版：{"immediate":"…","chapter_impact":"…","ending_probability":"…","character_cost":"…","thematic_resonance":"…","regret_factor":"高","regret_reason":"…"}

8. **角色声纹卡（workshop:character_voice，按需）**：为主要角色生成声音指纹，约束对白风格一致性。
    - 从动机和背景推断说话方式，具体到可直接用于写台词的程度。
    - 输出模版：{"speaking_rhythm":"说话节奏（快/慢，短句/长句，直接/迂回）","vocabulary":"常用词汇类型和禁用词","defense_mechanism":"压力下的语言防御机制（如转移话题、反问、沉默）","lie_tells":"说谎时的语言特征（如过度解释、突然变得礼貌）","sample_lines":["一句展示其声音特征的示例台词","另一句"]}

## 产物

节点 `emotionFunction` / `sceneDesc` / `dialogue` 写入 Project；选项修订同步回 `choices`——**本阶段每完成一批节点的精修即合并写回项目目录的 `project.json`**（防止中途丢失，最终确认后文件即完整版）。结构见 `/references/data-model.md`。确认后进入阶段四。
