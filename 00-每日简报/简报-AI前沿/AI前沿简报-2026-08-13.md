8月12日深夜至13日，不到24小时内四件大事落地：DeepSeek-V4-Pro-0813 正式转正、DeepSeek 同步开源 agent harness「dsh」、阿里开源 2.4 万亿参数 MoE 旗舰 Qwen3.8-2.4T-A95B、xAI 发布 Grok 4.6；同日 Google 发布 Gemini 3.7 Flash。另一条主线是 agent skill 生态在 GitHub Trending 集体爆发——Google 官方 skill 仓库、Addy Osmani 的工程 skill 集、逆向安全 skill 路由包等同时在榜，"一切皆可 skill 化"成为本期最强社区信号。

## 一、模型与架构

- **DeepSeek-V4-Pro-0813 正式转正（GA）**
  - 简介：DeepSeek 于 8月12日深夜将旗舰 API 模型切换为 DeepSeek-V4-Pro-0813 并全量开放（8月13日为 GA 日）。官方 API 文档确认 `deepseek-v4-pro` 模型 ID 已更新至 0813 版本，调用方式不变。这是 DeepSeek 首个"后训练集中强化"式大版本：架构不动、靠大规模 RL 重训实现能力跃迁。
  - 技术原理（MoE + 后训练强化）：1.6T 总参数 MoE、激活约 49B；API 同时兼容 OpenAI Responses API 与 Anthropic API 双协议（base_url 分别为 `api.deepseek.com` 与 `api.deepseek.com/anthropic`），可直接作为 Claude Code / Copilot / OpenCode 等 harness 的后端。定价极具攻击性：缓存命中 0.025 元、输入 3 元、输出 6 元/百万 token。
  - 链接：[DeepSeek API 官方文档/新闻页](https://api-docs.deepseek.com/news)

- **xAI 发布 Grok 4.6**
  - 简介：xAI 于 8月12日晚（美西）发布 Grok 4.6，8月13日全网铺开。官方定位为知识工作与编码智能体的旗舰升级，Artificial Analysis 同日发布独立基准分析。
  - 技术原理（大规模 RL 后训练）：约 1.5T 参数基座，在知识工作、编码、内核/系统、Web、CAD 等多域做大规模强化学习；HN 用户用 OpenRouter 做的同任务实测显示其编程"首次无 bug 率"显著高于 DeepSeek V4 Pro（成本 $1.41 vs $0.12，但省去返工）。
  - 链接：[xAI 官方公告](https://x.ai/news/grok-4-6) ｜ [Artificial Analysis 基准分析](https://artificialanalysis.ai/articles/grok-4-6-benchmarks-and-analysis) ｜ [HN 讨论](https://news.ycombinator.com/item?id=49274027)

- **阿里开源 Qwen3.8-2.4T-A95B：2.4 万亿参数开放权重 MoE**
  - 简介：阿里于 8月13日开源 Qwen3.8-2.4T-A95B，为当前规模最大的开放权重模型之一：总参数 2.4T、激活 95B，BF16 权重约 4.9TB。
  - 技术原理（超大规模稀疏 MoE）：MoE 稀疏激活将推理成本控制在 95B 激活量级；社区当日即跟进量化与部署方案（见板块三 Unsloth 1-bit 量化）。
  - 链接：[HuggingFace 模型页](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)

- **Google 发布 Gemini 3.7 Flash：三周一迭代的"编码与智能体主力马"**
  - 简介：Google 于 8月13日发布 Gemini 3.7 Flash（距 3.6 Flash 仅三周），主打编码、agentic 工作流与知识工作，年底前限时价 $0.75/$3.75 每百万 token（3.6 Flash 的一半）。已上线 Gemini API、AI Studio、Android Studio、Antigravity、Gemini Enterprise，并驱动 Gemini Spark 个人智能体。
  - 技术原理（agent 导向的后训练优化）：官方数据——DeepSWE v1.1 49.0%→65.3%、FrontierCode 1.1 Main 34.4%→43.6%、WebDev Arena Elo 1538→1588、GDP.pdf 22.0%→34.0%、AutomationBench 17.0%→30.4%；强调多步规划与工具调用上"更用功"，减少人工监督与重试；随附 CBRN 与网络进攻域的更新安全护栏。
  - 链接：[Google 官方博客](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/)

## 三、训练与数据

- **Unsloth 动态 1-bit 量化 Qwen3.8-2.4T：4.9TB → 397GB**
  - 简介：配合 Qwen3.8 开源，Unsloth 于 8月13日发布其动态量化版：BF16 权重 4.9TB 压缩至约 397GB（1-bit 级），使超大规模 MoE 的私有化部署门槛骤降。unslothai/unsloth 仓库当日在 GitHub Trending 日榜（+354 stars/日）。
  - 技术原理（分层选择性动态量化）：逐层动态选择量化位宽，对敏感层保留更高精度、其余层压至 1-bit 级（dynamic n-bit），在体积与精度间取得平衡；与 QLoRA 系微调栈同生态。
  - 链接：[unsloth 仓库](https://github.com/unslothai/unsloth)（GitHub 日榜在榜）｜ [Unsloth HF 主页（量化权重发布处）](https://huggingface.co/unsloth)
