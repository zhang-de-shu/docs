## 一、模型与架构

- **智谱 GLM-5.3 发布：不换基座的纯后训练 Scaling，网络安全能力逼近全球最前列**
  - 简介：智谱 8 月 14 日中午发布 GLM-5.3，与 GLM-5.2 共用同一基座（744B 总参 / 40B 激活 MoE），全部能力增量来自后训练；承诺两周内开源权重（先做安全加固），并启动"开源的盾"安全计划。
  - 技术原理（后训练 Scaling / MoE）：核心方法是四件套——IndexShare 长上下文共享、SAO with compaction 长程 RL、slime 异步训练框架、以及"环境自动合成 pipeline"（研究 Agent 从真实任务中提取任务定义 → 自动生成可执行环境 → 评判 Agent 验证并封堵奖励捷径）。代表性结果：Terminal-Bench 3.0 4.6→28.3、DeepSWE v1.1 46.2→66.9、Agents' Last Exam 23.8→28.5、AutomationBench 26.2→48.2；Z.ai Code Bench High 档 31.4% 超过 Claude Opus 4.8 的 29.5% 且平均输出仅约 5 万 tokens（对方约 12 万）。

## 三、训练与数据

- **"基座不动、纯后训练"成为头部厂商换代主路径：GLM-5.3 与 DeepSeek V4 系列的方法学观察**
  - 简介：本期两个旗舰升级（GLM-5.2→GLM-5.3、DeepSeek V4-Flash-0731→V4-Pro-0813）均不换基座、只重训后训练阶段，且都明确将此作为技术叙事的核心，标志后训练（RL + 环境合成 + 长程任务训练）已成为独立于预训练的规模化能力来源。
  - 技术原理（后训练 / RL 基础设施）：GLM-5.3 披露的完整后训练栈包括——SAO with compaction（带上下文压缩的长程强化学习，支撑跨天级任务）、IndexShare（长上下文中间状态共享，降低多轮训练/推理冗余）、slime（异步 RL 训练框架，缓解 rollout 与训练不同步的空转）、环境自动合成 pipeline（研究 Agent 提取任务 → 生成可执行环境 → 评判 Agent 验证 → 自动封堵奖励捷径），这套"环境即数据"的范式是 Agent 类基准大幅提分的直接原因。
  - 链接：[GLM-5.3 官方博客（方法细节）](https://z.ai/blog/glm-5.3) ｜ [DeepSeek 官方公告](https://api-docs.deepseek.com/zh-cn/news/news260813)
