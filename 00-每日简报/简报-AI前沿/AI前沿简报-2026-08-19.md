## 一、模型与架构

- **智谱 GLM-5.3 API 正式上线（8/14 发布，8/19 凌晨 API 开放）**
  - 简介：智谱迄今最强开源模型，总参数 743B，Artificial Analysis Intelligence Index 得 60 分，进入与 Claude Fable 5、GPT-5.6 Sol 同一的前沿能力区间，与 Kimi K3 并列开源模型第一；API 定价与 GLM-5.2 一致，完整权重拟于下周五以负责任方式开源。
  - 技术原理（后训练 Scaling）：基座与 GLM-5.2 完全相同，能力跃升全部来自极致后训练——IndexShare 架构、SAO（单轨迹异步优化）与新一代 Slime 强化学习框架，支撑数十倍长程任务环境中的长时 RL；Terminal-Bench 3.0 由 4.6→28.3，DeepSWE v1.1 由 46.2→66.9，Agents' Last Exam 由 23.8→28.5。同时涌现防御性网络安全能力（CyberGym 白盒漏洞发现 84.5%，略超 Mythos 5 与 GPT-5.6 Sol），红队累计发现 2,436 个漏洞（含 DNS 协议中潜伏 40 余年的协议级漏洞），并同步启动面向开源社区的"开源的盾"安全计划。
  - 链接：[智谱官方研究页](https://www.zhipuai.cn/zh/research/162) ｜ [技术博客](https://z.ai/blog/glm-5.3)

## 三、训练与数据

- **Agentic ESOpt：最小 GPU 需求微调长程 LLM 智能体**
  - 简介：8/19 HF 日榜论文第 2 名（91 赞），指出 RL 在长程 agent 训练上的局限，提出 GPU 需求极低的替代训练路线。
  - 技术原理（训练方法）：长程 agentic 推理带来指数分支的交互与稀疏奖励，RL 的反向传播训练栈使大模型微调不切实际、信用分配也显著更难；本文主张以演化策略式优化（ESOpt）替代传统 RL 完成长程 agent 微调。
  - 链接：[HF Papers](https://huggingface.co/papers/2608.17310)
- **Agent Lightning v1.0：迈向"被 harness 化的" Agentic RL**
  - 简介：微软 Agentic RL 训练框架 1.0 正式版（8/19 日榜，16 赞），正式提出并命名 "harnessed agentic RL" 范式。
  - 技术原理（RL 训练框架）：解耦架构通过 LLM endpoint proxy 把运行在 harness 内的任意 agent 接入 RL 训练；该范式已被 verl Uni-Agent、AReaL 2.0、Slime、Polar 等框架采纳，成为 agentic RL 的主流接入方式之一。
  - 链接：[HF Papers](https://huggingface.co/papers/2608.17528)
- **CoinVE-200K：组合式指令引导视频编辑数据集**
  - 简介：8/19 HF 日榜发布的大规模高质量视频编辑数据集（13 赞），填补组合式（多意图联合）指令视频编辑的数据空白。
  - 技术原理（数据集构建）：现有数据集多聚焦单一编辑操作，CoinVE-200K 要求在同一段视频内联合理解并忠实执行多条编辑意图，提供 20 万级配对样本。
  - 链接：[HF Papers](https://huggingface.co/papers/2608.17566)
