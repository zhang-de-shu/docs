## 二、多模态模型与应用

- **腾讯混元 AuK：开源语音生成与编辑基础模型（HF 当日热榜 152 票）**
  - 简介：AuK 是统一语音生成与编辑的开源基础模型，以自然语言指令+音频上下文为统一接口，覆盖语音生成、内容编辑、增强与分离、副语言编辑、声学编辑五大任务族。
  - 技术原理（音频生成）：构建约 30.3 亿条指令-音频实例、195 万小时有效监督数据；架构 = 多模态 LLM 做语义条件 + 语音/通用音频/音乐联合训练的 VAE 做声学条件 + 混合 rectified-flow Transformer（双流 MMDiT）生成。
  - 链接：[arXiv:2609.08936](https://arxiv.org/abs/2609.08936) ｜ [HF Papers](https://huggingface.co/papers/2609.08936)
- **腾讯混元 Gander（Omni Interaction Agent）：端到端全双工交互智能体（HF 热榜 137 票）**
  - 简介：Gander 在单一框架内统一全模态感知、实时交互与 agent 能力，持续接收视频/语音/文本流式输入，支持日常对话与复杂工作流场景的全双工交互——用户可随时打断，模型也会主动给中间反馈、追问。
  - 技术原理（全模态实时交互）：两项关键设计：Cerebellum-Brain（小脑-大脑）协作架构分离实时响应与深度推理；流式多模态输入原生支持，摆脱回合制范式。
  - 链接：[arXiv:2609.08977](https://arxiv.org/abs/2609.08977) ｜ [HF Papers](https://huggingface.co/papers/2609.08977)
- **Mask Forcing：自回归视频扩散蒸馏的双噪声掩码 rollout**
  - 简介：针对实时视频生成中 AR 视频扩散模型蒸馏后过饱和、过平滑的问题提出改进方案。
  - 技术原理（视频生成）：诊断出根因是 DMD（分布匹配蒸馏）反向 KL 目标的 mode-seeking 行为导致学生分布坍缩到教师分布的少数模式；提出 Dual-Noise Masking Rollout 对 AR 学生自 rollout 过程做双噪声扰动，缓解模式坍缩、提升视觉质量与真实感。
  - 链接：[arXiv:2609.09123](https://arxiv.org/abs/2609.09123)
- **Marigold V2：重访扩散 Transformer 做单目深度估计（华为 Bayer Lab，HF 热榜 111 票）**
  - 简介：经典 Marigold 深度估计系列的 V2 版本，将 DiT 架构重新引入单目深度估计并取得 SOTA 级表现。
  - 技术原理（视觉生成式感知）：用扩散 Transformer 作为深度估计骨干，利用生成式先验提升零样本泛化；面向机器人/AR 等下游几何感知任务。
  - 链接：[arXiv:2609.08084](https://arxiv.org/abs/2609.08084) ｜ [HF Papers](https://huggingface.co/papers/2609.08084)

## 三、训练与数据

## 四、智能体、框架与 harness

- **NeoHorse-1：以"路由 harness"实现递归自我改进的 agent 原生模型家族（HF 热榜 70 票）**
  - 简介：提出 RSI（递归自我改进）的具体机制——AI 系统观察自身能力证据并将其转化为下一轮训练数据；NeoHorse-1 是通过 agentic post-training 开发的 agent 原生模型家族。

  - 链接：[arXiv:2609.08183](https://arxiv.org/abs/2609.08183) ｜ [HF Papers](https://huggingface.co/papers/2609.08183)

  - 简介：针对长程 agent 丢失目标、乱序调用工具、重复无效动作的问题，提出把"程序性知识"显式组织成图结构。
  - 技术原理（agent 编排）：类比知识图谱用 (实体,关系,实体) 三元组组织事实知识，Procedural Graph 用 (程序,关系,程序) 三元组组织"做什么、按什么顺序、在什么条件下做"的程序性知识，作为可自进化的执行结构约束 agent 生成。
