## 一、智能体、框架与 harness

- **DeepSeek Harness v0.1 开发者预览版开源(MIT),"一切皆插件"的 Agent 执行框架**
  - 发布日期:2026-08-13 晚(窗口前一日发布,热度爆发于本期:半小时 star 破万、42 小时破 10 万、21 小时 dsh-plugin 插件仓库超 1300 个)
  - 简介:DeepSeek 首款 Agent 产品,定位"Model + Harness = Agent"的开源 Agent 运行时,直接对标 OpenAI Codex 与 Anthropic Claude Code;npx @deepseek-ai/dsh web 一行命令拉起本地 Web 工作台。
  - 技术原理:基于 Cordis 插件元框架(微内核只管插件加载/卸载/依赖),模型、工具、技能、会话、沙箱、存储、循环调度、UI 全部插件化、无特权组件;预置标准/PTC(程序化工具调用,模型生成代码编排多步工具调用)/极简(基准测试)/创造四种运行模式;append-only 会话日志支持轨迹恢复、分叉与回放;官方提供 dsh-subagent-claude-code(把 Claude Code 作为子代理挂载)与 dsh-hooks-claude-code(兼容 Claude Code hooks 格式)两个互操作插件,内置约 40 家模型供应商接入路由。
  - 链接:[GitHub 仓库](https://github.com/deepseek-ai/deepseek-harness)
  - 交叉来源:[火山引擎官方接入文档(2026-08-14 更新)](https://www.volcengine.com/docs/82379/2637928)、财联社/快科技 08-13~14 报道
  - 可信度:高(GitHub 仓库、npm 包 @deepseek-ai/dsh、多家独立媒体一致)

- **上下文工程/harness 设计文章:本期窗口内无新增重磅官方工程文章**

## 二、编程智能体

- **智谱 Z.ai 发布 GLM-5.3:同一基座纯后训练,编程能力 +50%,涌现网络安全能力**
  - 发布日期:2026-08-14
  - 简介:官方称"最强开放权重编码模型";沿用 GLM-5.2 的 ~743B MoE 基座(1M 上下文),全部提升来自后训练 Scaling;Z.ai Code Bench 较 GLM-5.2 提升 50%,Terminal-Bench 3.0 从 4.6 跃升至 28.3(开源第一),DeepSWE v1.1 46.2→66.9;权重将在安全评估后约两周开源。
  - 技术原理:后训练阶段把长程任务环境扩大数十倍——由专业智能体参照真实软件项目自动生成"模拟开发者工作站"沙盒并定制练习,独立评判智能体预先验证任务可解性;RL 栈基于 slime(异步 RL 训练框架)、SAO(异步强化学习)与 IndexShare(长上下文),自动生成奖励信号的数据管道;CyberGym 84.5%、ExploitBench 54.4%,已在 269 个真实项目中发现 2436 个漏洞(1097 个中高危);思考模式强制开启(low/high/max 三档)。
  - 链接:[官方技术博客 z.ai/blog/glm-5.3](https://z.ai/blog/glm-5.3)
  - 交叉来源:界面新闻/至顶科技 08-14~15 报道、DataLearner 模型页(08-14)
  - 可信度:高(官方博客 + 多家媒体一致;权重尚未放出,自报分数待第三方复现)

- **OpenAI 向 ChatGPT/Codex 订阅用户放开 GPT-5.6 Sol 的 1M 上下文**
  - 发布日期:2026-08-16 晚 ~ 08-17(Tibo 官宣)
  - 简介:Codex 中 GPT-5.6 Sol 的 100 万 token 上下文窗口原仅限 API key 使用,现已对 ChatGPT 账号生效;三行配置即可启用(model_context_window=1000000、model_auto_compact_token_limit=900000),约 90 万 token 时自动压缩历史。
  - 技术原理:Codex 默认上下文长度(约 272k)是性能/成本调优后的"计费护栏"——超过后 token 消耗速度翻倍(输入超 272K 价格翻倍);官方长上下文评测 MRCR v2 显示 GPT-5.6 Sol 在 256K–512K 区间 91.5%、512K–1M 降到 73.8%,因此官方主推 auto-compact(自动压缩旧历史)而非拉满窗口;此次是把选择权交给用户。
  - 链接:[OpenAI 开发者社区官方讨论帖(含 Tibo 原文)](https://community.openai.com/t/1-million-context-to-enable-professional-workloads/1390013)
  - 交叉来源:IT之家 08-17、腾讯研究院 AI 速递 08-18
  - 可信度:高(OpenAI 官方论坛 + 工程师 X 原帖被多方一致引述)

- **Claude Code v2.1.227–233:多会话 Agent 成为默认路径(子代理 fork + 跨会话消息)**
  - 发布日期:2026-08-11 ~ 08-15 区间(v2.1.233 约 08-14/15)
  - 简介:本周 Claude Code 主线是把"并行多 Agent 协作"变成默认能力:v2.1.232 默认开启 fork subagent、非 teammate 代理转入后台、提示框 @ 其他 session + SendMessage 跨会话直投;v2.1.233 补上 GitLab MR URL 接入 --worktree/claude agents、forward_user_identity 网关归因、Linux Bash 可选 cgroup 内存限制,并修复 2.1.232 的 Bash 权限回归。
  - 技术原理:fork 出的子代理继承完整 conversation 与 prompt cache(缓存前缀复用,同前缀 workflow fan-out 错峰启动);会话寻址支持重名处理与 accept/hold/refuse/dialog expiry;GitLab 侧扩展到凭据脱敏、插件 marketplace 分发与 nested subgroup 工作树;整体构成"当前 session fork → 后台执行 → @/SendMessage 协调 → 状态回流可审计"的长任务执行闭环。
  - 链接:[Claude Code 官方 Release Notes](https://docs.anthropic.com/en/release-notes/claude-code)
  - 交叉来源:[releasebot.io 聚合](https://releasebot.io/updates/anthropic/claude-code)、change8.dev v2.1.233(2026-08-14)、VibeCoder 周汇总(08-17)
  - 可信度:中-高(版本内容由多个独立聚合源交叉一致;本次运行环境无法直连官方页逐字核对)

- **Cursor:Cloud Agents 从预制 Builds 启动,首 token 提速 3 倍**
  - 发布日期:2026-08-13(窗口边缘,本期生效发酵)
  - 简介:Cursor changelog 显示 Cloud Agents 现在从后台预制的"Builds"(就绪环境副本)启动,首 token 时间缩短 3 倍;坏提交或依赖更新破坏环境时,agent 自动沿用最近一次成功构建;dashboard 新增 Builds 标签页展示状态、日志与 commit SHA。

  - 链接:[Cursor 官方 Changelog](https://cursor.com/changelog)
  - 交叉来源:[releases.sh/cursor 镜像](https://releases.sh/cursor)、码农财经周报(08-15)

## 三、计算机使用 / GUI 智能体

- **Qwen3.8-27B 刷新开源小模型的 computer use 水位:OSWorld-Verified 84.3 / AndroidWorld 81.9**
  - 发布日期:2026-08-14
  - 简介:阿里开源的 Qwen3.8-27B 在计算机使用两大基准上给出同尺寸最强成绩——OSWorld-Verified 84.3(桌面真实虚拟机任务)、AndroidWorld 81.9(手机智能体),意味着 27B 级开源模型已可本地驱动桌面/手机自动化。
  - 技术原理:27B 稠密原生多模态架构(文本/图像/视频输入),262K 原生上下文可扩展到 1M 以容纳长流程的截图历史与动作轨迹;视觉 grounding + 动作预测闭环操作 GUI,配合 vLLM/SGLang 本地部署。
  - 链接:[HuggingFace 模型卡 Qwen3.8-27B-FP8](https://huggingface.co/Qwen/Qwen3.8-27B-FP8)

- **BrowserOS:为 AI 智能体而生的开源浏览器,本期在国内热度爆发**
  - 发布日期:产品 8 月初发布(Product Hunt),窗口内 08-15 起国内集中报道、08-17 更新 0.47.18,GitHub star 12,000+
  - 简介:Chromium fork 的开源"智能体浏览器"(AGPL-3.0,YC 背景),让 Claude Code/Codex/Cursor 等编程智能体借用用户本机已登录的浏览器环境真正执行网页任务;多智能体并行、会话全程回放、数据全部留在本地。
  - 技术原理:内置 MCP 服务器(53+ 浏览器自动化工具:navigate/click/fill/extract 等),智能体通过 MCP 一键连接;一键导入 Chrome 登录态解决云端浏览器"数据中心 IP 被封/登录难"痛点;向智能体提供精简页面快照而非截图以降低 token 消耗;每个 agent 独立标签页 + 驾驶舱视图实时监控,会话录制为可拖拽回放视频;支持云端模型与 Ollama 本地模型。
  - 链接:[GitHub 仓库 browseros-ai/BrowserOS](https://github.com/browseros-ai/BrowserOS) | [官网](https://www.browseros.com)
  - 交叉来源:今日头条/AITNT 08-15 报道、Product Hunt 发布页
  - 可信度:中-高(仓库/官网一手;热度数据来自二手报道,发布时间早于窗口、热度在窗口内)
