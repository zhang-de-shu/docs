## 一、模型与架构

- **世界模型距"真仿真器"还有多远：200 篇代表作系统性能力评估**
  - 简介：以传统仿真器为外部标尺的系统性研究，评估生成式世界模型能否替代仿真器，覆盖 200 篇代表作。
  - 技术原理（综述/评估）：按潜在动力学、视频生成、JEPA 三条路线梳理，对照传统仿真器八项能力（物理引擎、交互、可控性、稳定性、状态反馈等）逐一评估。结论：世界模型在特定场景已实现交互与可控性的功能替代，但物理规律形式化保证、结构化状态反馈、长时程可复现演化仍显著落后——163 篇实现论文中仅 6 篇暴露运行时状态查询接口；据此提出六个研究方向。
  - 链接：[论文](https://arxiv.org/abs/2608.23070)
  - 日期：8月24日（arXiv 提交）

- **OpenRouter 匿名模型 "Ox Alpha" 持续霸榜，指纹取证指向 GLM-5.x（热度型）**
  - 简介：OpenRouter 于 8 月 20 日上线的匿名模型，窗口内（08-23~25）持续登顶调用榜并刷新单日调用纪录；1.048M 上下文，支持文本/图像/视频。

  - 链接：[OpenRouter 模型页](https://openrouter.ai/)（一手：平台自身模型与调用数据）

## 四、智能体、框架与 harness

- **Prime Agent：Prime Intellect 开源自改进式 RLM Harness**
  - 简介：开源长程任务 harness，按 Recursive Language Model（RLM）抽象用持久 IPython REPL 做程序化上下文处理，宣称把 ARC-AGI-3 RHAE Best@1 从 30% 提到 95.5%。
  - 技术原理（agent harness）：持久 REPL 承担程序化上下文管理与测试时计算；"Continual Harness" 跨轨迹保存历史、记忆、技能与子代理规格；递归子代理通过 agent 间直接通信协调；统一执行、恢复、验证与资源记账，把策略构造留给模型本身，目标是"防止 harness 失败变成模型失败"。
  - 链接：[论文](https://arxiv.org/abs/2608.23552) ｜ [GitHub 仓库](https://github.com/PrimeIntellect-ai/prime-agent)
  - 日期：8月24日（arXiv 提交）

- **OpenAI Codex Harness 开源后持续爆火：8月24日登顶 GitHub 日榜（热度型）**
  - 简介：OpenAI 8 月 19 日将 Codex Harness 全栈开源（Apache-2.0，含 CLI exec / SDK / app-server），本期热度爆发——8 月 24 日 GitHub 日榜第 1，单日 +2715 star，累计 11.5 万星。
  - 技术原理（编程智能体执行循环）：开源的 harness 执行层与模型解耦，官方数据显示同一 GPT-5.6 Sol 模型在 ARC-AGI-3 上经 harness 优化从 13.3% 提升至 38.3%，直观证明"执行脚手架本身就是巨大性能变量"，这也是本轮爆火的核心叙事。
  - 链接：[GitHub 仓库](https://github.com/openai/codex)
  - 日期：8月19日发布，8月24日登顶日榜（GitHub Trending 数据）

- **AutoSaddler：把 Harness 当代码自动优化的框架**
  - 简介：用执行失败轨迹离线迭代改进 agent 的提示/工具配置/控制逻辑，无需换模型即可显著提升长程任务表现。
  - 技术原理（harness 自动优化）：将 harness 改进建模为离线学习问题，按 mini-batch 失败信号迭代；三件套为失败轨迹深度诊断、把 harness 当代码做结构化补丁生成、基于验证的泛化感知更新筛选。在 GAIA2、SWE-Bench Pro、Terminal-Bench 2.0 上比基线分别提升 9.0/9.6/10.0 个百分点。
  - 链接：[论文](https://arxiv.org/abs/2608.23041)
  - 日期：8月24日（arXiv 提交）

- **Dual-Layer Agentic Memory：快写路由 + 慢巩固的双层代理记忆**
  - 简介：借鉴神经科学 CLS（互补学习系统）理论，把 agent 记忆管理从"读时过滤"前移到"写时路由"，并定期把外部记忆巩固进模型参数。
  - 技术原理（记忆系统）：输入知识分为 non-write / write-new / write-update 三类；写路由用"小模型→大模型"级联做成本感知二分类；写回阶段用 SFT 把高价值外部记忆选择性内化进参数。1.7B/8B 级联剪掉最多 68% 冗余外部记忆、升级请求不足 50%，仍保留全量基线 98% 以上的下游 QA EM。
  - 链接：[论文](https://arxiv.org/abs/2608.22215)
  - 日期：8月23日（arXiv 提交）

- **The Interaction Tax：多智能体通信会抹掉多样性**
  - 简介：发现让 agent 互读完整输出会使其方案一轮内趋同、抹平多模型多样性，提出"交互税"概念。
  - 技术原理（多智能体编排）：11 个 verifier 打分的等预算对照实验显示：完整方案共享导致提案向"第一个看到的解"收敛，是弱默认策略；独立提案生成可避免坍缩；批判（critique）只在被违反规则对 LLM 易发现易修复时才有帮助——为"何时通信、通信什么"提供调度依据。
  - 链接：[论文](https://arxiv.org/abs/2608.23541)
  - 日期：8月24日（arXiv 提交）

- **Evaluating Modern RAG：文本/多模态、稠密/晚期交互管线系统评测**
  - 简介：对主流 RAG 管线（纯文本、VLM 多模态、dense、late-interaction）做量化对比，给出按语料选管线的选型方法。
  - 技术原理（RAG 评测）：针对表格/版式/视觉元素承载语义的文档，评测多模态管线与文本管线的检索质量-算力权衡，提出数据驱动的定量选型方法（多模态提升检索质量但计算/内存成本更高）。
  - 链接：[论文](https://arxiv.org/abs/2608.23176)
  - 日期：8月24日（arXiv 提交）

  - 技术原理（生物基础模型）：结合稠密双向自注意力、单核苷酸 token 化和"注意力隔离的序列打包"（避免打包样本间注意力泄漏）做 10,240 nt 原生预训练；40% 重掩码破坏下仍保持强恢复能力。
  - 链接：[论文](https://arxiv.org/abs/2608.22849)
  - 日期：8月24日（arXiv 提交）

- **PHASE：局部哈密顿量编码全局蛋白构象系综并全原子回映射**
  - 简介：把原子级蛋白构象系综转化为显式、可解释的统计模型，应用于腺苷 A2A 受体约 37μs 模拟数据。
  - 技术原理（计算生物）：仅含 6Å 内局部残基耦合的哈密顿量即可重现逐残基与成对微态统计、甚至复现未直接耦合残基间的相关性，并支持从粗粒化统计模型全原子回映射，为 GPCR 构象景观研究提供可解释工具。
  - 链接：[论文](https://arxiv.org/abs/2608.23490)
  - 日期：8月24日（arXiv 提交）

- **广义 Abell-Tersoff 键序势：显式高阶多体关联提升机器学习原子间势外推能力**
  - 简介：半参数机器学习原子间势（MLIP），改善对训练域外构型（高温高压）的外推。
  - 技术原理（AI for 材料）：在 Abell-Tersoff 键序势上引入化学先验函数形式与显式高阶多体关联，以物理约束正则化模型；硅、碳、水与小分子数据集上插值精度相当、高压高温外推显著更稳。
  - 链接：[论文](https://arxiv.org/abs/2608.22933)
  - 日期：8月24日（arXiv 提交）
