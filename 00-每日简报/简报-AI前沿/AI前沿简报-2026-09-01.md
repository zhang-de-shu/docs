## 一、模型与架构

- **DeepSeek-V4-Flash-Vision-Exp 开源：V4 家族首个多模态模型**
  - 简介：DeepSeek 于 8/21 在 API 上线、8/31 在 HuggingFace 以 MIT 协议开源权重与全链路代码；305B 总参、每 token 激活 13B 的 MoE 多模态模型，多模态 Agent 能力官方称接近 Opus-4.8，部分基准反超。
  - 技术原理（MoE 多模态基座）：在 V4-Flash 纯文本架构上加视觉模块（视觉编码器 + Aligner），同步开源 DFlash Attention、MoE、Hyper-Connections、DSpark 等核心模块与最小化 PyTorch 推理代码。单图 token 上限压到 384（高分辨率等比压缩至约 800x800），把视觉输入成本固定到极低。ZeroBench 35.0 反超 Opus-4.8 的 34.0，DeepSWE 从 54.4 升至 59.3 登顶，且纯文本 Agent 能力不降反升（Terminal Bench 83.9）——加"眼睛"不伤"脑子"。
  - 链接：[官方 Changelog](https://api-docs.deepseek.com/updates/) ｜ [HuggingFace 模型页](https://huggingface.co/deepseek-ai)

- **Qwen3.8-Next 架构设计论文公开**
  - 简介：Qwen 团队公开下一代基座 Qwen3.8-Next 的架构设计报告，覆盖架构选型、评估、效率与训练稳定性。
  - 技术原理（架构设计报告）：报告式论文，系统给出新一代架构相对前代的改进设计与消融证据，重点在训练稳定性与推理效率的权衡，是观察国产基座架构演进方向的一手材料。
  - 链接：[arXiv](https://arxiv.org/abs/2608.30320)

- **科大讯飞开源星火 X2.5-4B / 1.7B：端侧首个百万上下文模型（9/1 发布）**
  - 简介：科大讯飞子公司词元星火发布并开源两款端侧通用大模型，是端侧模型中首个原生支持最长 100 万 token 上下文的产品；9/7 还将发布 293B 旗舰版。
  - 技术原理（端侧混合注意力 + 超长上下文）：两款模型采用混合注意力架构，约 20 万亿 token 预训练、基于全国产算力完成全流程训练，再经高质量 SFT 与强化学习优化智能体、代码、数学与指令遵循。面向机器人/智能家居等连续执行场景，1.7B 在 Domux 智能家居测试集控制指令端到端正确率 90.3%、平均响应 0.85 秒；兼容 vLLM、SGLang、llama.cpp，可经 Ollama/LM Studio 快速部署。
  - 链接：[GitHub 仓库](https://github.com/XHToken/Spark-X2.5) ｜ [HuggingFace 模型集合](https://huggingface.co/collections/XHToken/spark-x25)

  - 技术原理（多智能体编排 + 生成模型组合）：把长创作任务（剧本→分镜→生成→审校）拆给多个专职 agent 协同流水线执行，底层挂接 Wan3.0 视频与 Qwen-Image-3.0 图像模型，属于"编排层升级拉动生成模型落地"的典型形态。

- **DreamX-Creator：2K 原生音视频同步生成**
  - 简介：AMAP-ML 团队发布 DreamX-Creator，支持 2K 分辨率、音频与视频原生同步生成，登上 HuggingFace Daily Papers 热榜（86 upvotes）。
  - 技术原理（音视频联合生成）：将音轨与视频帧在同一生成框架内联合建模，避免"先视频后配音"的两段式管线带来的音画错位，实现原生的视听同步输出。

## 三、训练与数据

- **Does On-Policy Distillation Really Distill?：质疑在策略蒸馏的真实收益**
  - 简介：Purdue 团队论文，系统检验当下流行的 on-policy distillation 是否真的在"蒸馏"教师知识，登上 HF Daily Papers 热榜（93 upvotes）。
  - 技术原理（蒸馏机理分析）：通过控制实验拆解 on-policy 蒸馏的收益来源，区分"学生从教师分布学到知识"与"学生只是获得了更好的探索信号（类似 RL 正则）"两种解释，对当前大量采用该范式的后训练管线提出实证质疑。
  - 链接：[arXiv](https://arxiv.org/abs/2608.31046) ｜ [HF Papers](https://huggingface.co/papers/2608.31046)

- **Normalized Low-Rank Adaptation：LoRA 归一化改进**
  - 简介：提出在低秩适配中引入归一化的训练方法，改善 LoRA 微调的稳定性与效果。
  - 技术原理（PEFT）：分析 LoRA 低秩更新在训练动态中的尺度失衡问题，在低秩分支加入归一化处理，使适配层更新方向与幅度更稳定，可与现有 LoRA 生态无缝替换。
  - 链接：[arXiv](https://arxiv.org/abs/2608.31036)

## 七、计算机使用 / GUI 智能体

- **Runway 发布 Solaris：界面世界模型（9/1）**
  - 简介：Runway 发布 Solaris——首个"界面世界模型"：不再让模型写 HTML/代码再渲染，而是像生成视频一样**实时逐帧生成可交互界面**，在盲测中指令遵循 61% 对 24% 领先"用 Claude Opus 5 写 UI 代码"的传统路线。
  - 技术原理（自回归帧生成 + 蒸馏 + 自我训练）：建立在 Gen-4.5 与 GWM-1 基座之上，三项核心技术：① 自回归逐帧生成界面状态；② 去噪蒸馏加速；③ 用模型自身输出作训练数据自我迭代。架构上采用"双模型"分工——LLM 当"导演"理解指令与意图，渲染模型负责生成帧。这代表 GUI 生成从"代码生成范式"转向"世界模型范式"：界面成为可直接生成的动态环境。
  - 链接：[官方研究博客](https://runwayml.com/news/research/introducing-solaris)
