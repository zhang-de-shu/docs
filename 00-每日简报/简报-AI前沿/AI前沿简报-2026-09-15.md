# AI领域前沿简报 · 2026-09-15

> 聚焦：通用

本期最值得关注的两件事：一是上海AI实验室/复旦开源 744B MoE 智能体基座 **Atria Dawn Preview**（MIT 协议，多项 agentic benchmark 登顶，HF Daily Papers 当日热度第二）；二是实时视频生成进入"交互时代"——生数科技 **Vidu S2** 与阶跃星辰 **StepAudio 3** 同日发布，分别把实时数字人视频和全双工语音推到公开榜单第一。工程侧，Anthropic 的 **Claude Mods**（Function Hooks）开始上线，被视为比发新模型影响更大的 harness 架构变化。

## 一、模型与架构

- **Atria Dawn Preview：744B 开源 MoE 智能体基座**
  - 简介：上海AI实验室/复旦团队发布（权重9月11日开放、论文9月14日提交、9月15日登上 HF Daily Papers 热度榜第二，369 upvotes，本期热度高峰）。744B 总参数 MoE（基于 GLM-5.2 继续训练），MIT 协议，256K 上下文，主打长程智能体任务；在 16 项 benchmark 中 5 项取得公开最高分（AutomationBench 53.8、BFCL v4 77.0、DeepSearchQA 96.0、BrowseComp 92.5、CyberGym 86.5）。
  - 技术原理（基座模型/后训练）：核心是 Verifiable Experience Pipeline（可验证经验管线）——用可自动验证的任务轨迹做后训练数据筛选与强化；随权重开放了 769 条任务记录、56 人参与的人机协同研究数据（约1/3任务"无AI不可行"）。编程是其短板（Terminal-Bench 2.1 78.3、SWE-bench Pro 59.6）；沐曦完成 Day-0 国产算力适配。
  - 链接：[论文](https://arxiv.org/abs/2609.15818) ｜ [HF 权重](https://huggingface.co/internlm/Atria-Dawn-Preview) ｜ [GitHub](https://github.com/atria-asi/Atria-Dawn-Preview) ｜ [官网](https://atria-asi.ai)

- **ZGCM-1：7名博士生3个月从零训练的7B全开源模型**
  - 简介：北京中关村学院7名博士生用3个月从零训练 7B 模型，代码、数据、权重、训练日志全公开（9月15日登上 HF Daily Papers，291 upvotes），是"AI4AI"（数百个 Agent 参与训练实践）的完整可复现样本。
  - 技术原理（架构/训练）：局部与全局注意力结合架构；16K 序列预训练效率提升 4.2 倍，256K 上下文吞吐提升 3.94 倍；数学与 agentic search 方向在同规模模型中领先。
  - 链接：[论文](https://arxiv.org/abs/2609.13356) ｜ [HF Papers](https://huggingface.co/papers/2609.13356)

- **紫东太初 ZDTaichu5.0-9B：面向物理世界的开源多模态模型**
  - 简介：中科院自动化所紫东太初9月15日宣布开源 9B 物理世界多模态大模型，9项空间理解 benchmark 中8项同量级第一，并罕见地开放了全套数据生产管线（预训练→SFT→退火→GRPO RLVR）。
  - 技术原理（多模态/推理）：提出 adaptive loop reasoning（自适应循环推理）——以熵为门控信号决定是否触发内部迭代深思，与 GPT-6 Astra 的 Loop Transformer 思路可对照；面向具身/空间智能场景优化视觉-语言对齐。
  - 链接：[官方发布（紫东太初官网）](https://www.zdtaichu.com)（模型权重见其官方 HF/GitHub 通道）

## 二、多模态模型与应用

- **Vidu S2：实时交互式视频生成（9月15日发布）**
  - 简介：生数科技发布 Vidu S2 系列：S2-Avatar 实现 720p、25–42FPS 的实时交互式数字人（支持中途注入参考图换脸/换装）；S2-Editing 支持实时视频流编辑；并支持左右眼空间视频（VR 用）。StreamAV-Bench 九项指标 SOTA；9月15日登顶 HF Daily Papers（499 upvotes，当日第一）。
  - 技术原理（视频生成）：提出 Self-Replay Forcing 与 Hybrid Forcing 解决流式自回归漂移；Backbone-Refiner 双阶段架构 + 帧对齐稀疏注意力保证实时性；工程上用 SageAttention/SpargeAttention、W8A8 量化与 CUDA Graphs 压延迟；后训练用 DPO + Streaming NFT；VLM Agent 负责交互编排。
  - 链接：[论文](https://arxiv.org/abs/2609.11638) ｜ [体验入口](https://vidu.cn/vidu-stream)

- **StepAudio 3 系列：五款语音模型同日开源/上线（9月15日）**
  - 简介：阶跃星辰发布 StepAudio 3 系列共5个模型（Realtime/ASR/TTS/Gen/Music）。Realtime 为全双工实时对话模型，在 Artificial Analysis 的 Conversational Dynamics（98.9%）与 Speech Reasoning（99.7%）两项登顶第一；ASR WER 1.7%（并列第一）。
  - 技术原理（语音）：Realtime 采用全双工架构（边听边说、可打断）；TTS 支持流式输出与副语言控制（笑声/叹息等）；Gen 为统一音频-场景生成模型；Music 用 ABC 记谱法表示实现多轮可控作曲。均已上线阶跃星辰开放平台。
  - 链接：[官方平台](https://platform.stepfun.com)（模型与公告见 StepFun 开放平台/GitHub 官方通道）

- **FireRedTTS3：24语言21方言开源 TTS**
  - 简介：小红书 FireRed 团队开源 FireRedTTS3，支持24种语言与21种中文方言，Apache-2.0 协议；9月15日出现在机器之心当日开源热榜。
  - 技术原理（语音合成）：大规模多语言/方言数据训练的 LLM-based TTS，主打方言覆盖与零样本音色克隆。
  - 链接：[GitHub](https://github.com/FireRedTeam/FireRedTTS3)

## 三、训练与数据

- **Dream-RSI：把发现历史变成"回放模拟器"**
  - 简介：Google 等团队提出 Dream-RSI（9月14日提交，9月15日 HF Daily Papers 260 upvotes），针对递归自我改进（RSI）智能体的元探索训练，最高减少 162 倍 agent 调用成本。
  - 技术原理（RL/自我改进）：将 agent 自己的发现历史构造成离线回放模拟器，让模型在"做梦"（dreaming）中对已探索轨迹做 off-policy 重放与反事实重组，以极低成本获得元探索能力的提升，而不必反复真跑环境。
  - 链接：[论文](https://arxiv.org/abs/2609.14858) ｜ [GitHub](https://github.com/zhengkid/Dream-RSI)

## 四、智能体、框架与 harness

- **RSIAgent：不更新参数、靠自主探索超越 GPT-6 Astra**
  - 简介：Aether AI（联合 UCSD/UIC）提出训练无关的多智能体递归自我改进框架（论文9月14日提交，9月15日机器之心等报道并登 HF Daily Papers）。在 OSWorld 2.0 上把开源模型提升到 78.98%（GPT-6 Astra 为 72.60%），Agents' Last Exam 达 84.82%。

  - 链接：[论文](https://arxiv.org/abs/2609.15364) ｜ [GitHub](https://github.com/AetherLabsAI/RSIAgent) ｜ [项目主页](https://aetherlabsai.github.io/RSIAgent/)

- **Claude Mods 开始上线（9月15日）：Function Hooks 重构 Claude Code 扩展体系**
  - 简介：Anthropic 的 Claude Mods 于9月15日开始上线（Early Access），允许开发者用 TypeScript 函数深度定制 Claude Code 的行为与界面——拦截工具调用、改写 UI 渲染、注入安全策略；社区已有人在 CLI 界面里实现俄罗斯方块。Anthropic 计划将现有功能逐步迁移为 Mod 形态。
  - 技术原理（harness）：核心是 Function Hooks——与旧式"外部脚本 hook"不同，Mod 以类型化中间件形式嵌入 agent 执行管线，多个 Mod 按注册顺序形成洋葱模型（类似 Express/Koa），可监听 `tool.call`、`session.start`、`turn.complete` 等事件并通过 `next(event)` 继续或 `deny` 拦截；官方已开源 diff（差异面板）、sec-default（企业策略保护）、telemetry 三个内置 Mod；实验开关 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`。
  - 链接：[Claude Code 官方 release notes](https://docs.anthropic.com/en/release-notes/claude-code)
