## 一、模型与架构

- **Ox Alpha（"牛来"）周末热度登顶：累计处理 7.55T tokens，服务端取证进一步锁死智谱** 「热度型：8月20日上线，本期持续爆火，较上期新增证据链」
  - 简介：上期收录的 OpenRouter 匿名全模态推理模型本期热度到达峰值。OpenRouter Stealth 页显示累计处理 7.55T tokens（8/21 单日 59.7B），最大调用方为 Hermes Agent（4600 亿 tokens）与 Claude Code（2950 亿 tokens）；Stripe CEO Patrick Collison 试用后公开评价"印象深刻"。官方未认领，身份揭晓或看 8/28 智谱 GLM-5.3 开源。
  - 技术原理（指纹取证）：本期新增服务端取证——畸形请求触发的 Java 堆栈暴露内部类 `com.wd.paas.api.domain.v4.chat.ChatCompletionRequest`，路径与 Z.ai 公开 API 结构对应，错误码 1214 与 GLM 系逐字一致；叠加此前 tokenizer（与 GLM-5.3 恒定 +75 token 差）、视频编码器（与 GLM-5V-Turbo 逐 token 一致）证据，独立研究者给出约 99% 概率为智谱 GLM-5.x（可能是补视觉的 GLM-5.3V）的判断。控制变量实验证明指纹锁定的是 API 运营方而非权重来源。
  - 链接：[OpenRouter 模型页](https://openrouter.ai/stealth/ox-alpha) ｜ [Stealth provider 页](https://openrouter.ai/provider/stealth)

- **Google 提出 EnvHarness：把 harness 思想搬到环境侧，让静态基准变成可进化的训练环境** 「8月20日提交，8/23 解读峰值」
  - 简介：Google Cloud AI Research 联合华盛顿大学（圣路易斯）、UNC 提出 Environment Harness，用插件组件包裹静态智能体环境以重塑其行为而不改底层代码，是周末讨论度最高的 harness 方向论文（机器之心 8/23 深度解读）。
  - 技术原理（环境侧 harness + 环境-策略协同进化）：EnvHarness 是环境与智能体交互层之间的可编程插件层，只通过标准 reset()/step() 接口操作，提供 Stage（重塑回合初始状态）、Contract（约束合法动作与观测）、Chain（跨环境任务串联）三类组件，重塑后环境继承原基准的人工验证器保持分数可比；配套 EnvRigger 把目标策略当黑盒，读轨迹诊断弱点、自动合成针对性组件并迭代验证。效果：ALFWorld 61.7→68.3、WebArena 38.7→41.6、SWE-bench Verified 47.7→52.6。代码 Apache-2.0 开源。
  - 链接：[论文](https://arxiv.org/abs/2608.19880) ｜ [仓库](https://github.com/google-research/envharness)

- **StateMemBench：智能体记忆系统"记得住事实、追不上状态变化"的首个专项基准** 「8月20日提交」
  - 简介：UIUC 团队发布 StateMemBench 基准与 state-first 记忆方法 StateMem，专测多会话场景下记忆系统能否追踪不断演化的状态（区分"当前状态/已覆盖旧状态/无法判定"）。
  - 技术原理（记忆系统评测与方法）：234 个多会话场景、闭集评分；StateMem 以状态优先方式组织记忆，同一 backbone 下当前状态准确率约为最强基线的 1.8 倍（0.205→0.363，DeepSeek-V4-Flash）；作为轻量包装器插入 6 个现有记忆/检索后端可带来 +32～+67 分提升，成本匹配控制实验表明其中 +15～+32 分归因于状态结构本身而非额外算力。
  - 链接：[论文](https://arxiv.org/abs/2608.19652)
