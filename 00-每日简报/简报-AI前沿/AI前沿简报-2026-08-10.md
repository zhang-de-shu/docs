## 一、模型层 / 开源生态

- **Meta Muse Glimmer 开放权重发布：30B 智能体模型，单卡 24GB 可跑（8/10 发布）**
  - 简介：Meta 8 月 10 日发布 Muse Glimmer 开放权重模型——30B 参数的智能体（agentic）模型，Apache 2.0 协议，原生多模态稠密架构（文本+图像交错生成，支持 100+ 语言），由旗舰闭源模型 Muse Spark 蒸馏而来；官方主打"单张消费级 GPU（24GB 显存）即可运行"，4-bit 量化后体积小于 20GB。这是 Meta 继 Llama 系之后在智能体模型方向最激进的一次开源。
  - 技术原理（蒸馏 + agent-loop 训练 + 投机解码）：三条技术主线：① 全程在智能体闭环（agent loop）中训练——规划、函数调用、自我检查、故障恢复作为一等公民写进训练循环，而非事后微调；② 从 Muse Spark 蒸馏，保留旗舰模型的工具使用与长程任务能力的同时压到 30B 稠密规模；③ 推理侧配套 DFlash 投机解码，官方宣称 RTX 5090 上约 3.1 倍吞吐。智能体基准（对比 Qwen3.6-27B）：MCP Atlas 75.5 vs 62.5、DeepSearch QA 74.6 vs 71.1、AIME 2026 94.7 vs 94.1；但在 OSWorld-Verified 与 TerminalBench 2.1 上落后，"桌面/终端操作类"智能体能力仍是短板。同日 Meta 预告 Muse Spark 1.2 也将推出开放权重版本，并宣布新的发布安全治理结构与 10 亿美元社区基金。
  - 链接：[HuggingFace · meta-models](https://huggingface.co/meta-models) ｜ [Meta 官方发布页](https://go.meta.me/museglimmer) ｜ [开发者文档](https://developer.meta.com/ai/models/muse-glimmer/)

## 二、部署与应用层

- **Approximate Speculative Decoding（ASD）：预算制"近似验证"再榨投机解码吞吐（arXiv 8/4 提交，8/10 进入 arXiv 新榜）**
  - 简介：清华系团队（Yuannuo Feng 等）提出免训练的投机解码验证器 ASD：不再"第一个不匹配 token 即截断"，而是在受控预算内接受少量低代价不匹配、复用目标模型已打分的后缀。固定负载吞吐比严格验证提升 3.05%–15.26%，Qwen3-14B + DSpark-14B 七任务平均 +7.78%。
  - 技术原理（验证器侧近似 + regret 预算）：标准贪婪验证在首个 draft-target 不匹配处截断，丢弃目标模型本次前向已算出的剩余分布。ASD 的关键观察是：若接受某个早期不匹配，其后一段 draft token 可能已在"既成前缀"下仍是目标贪婪解，可直接复用而无需额外前向。实现上以三重闸门控制近似代价：局部 target-logit regret 阈值、每块例外上限、贯穿整个请求的持久 regret 预算；预算设为 0 时严格退化为标准贪婪验证，无需新 draft 模型、无需微调。DeepSeek-V4-Flash（284B）+ DSpark 的 FP4-to-FP8 兼容场景下，GSM8K/MATH-500 验证侧接受率再提升约 10%–16%。
  - 链接：[arXiv:2608.03447](https://arxiv.org/abs/2608.03447) ｜ [GitHub · ASD](https://github.com/Kissmetothemoon/ASD)

- **PPIO Fusion 融合模型：多模型融合网关，主打"旗舰级效果、十分之一成本"（8 月上旬发布，本期仍在发酵）**
  - 简介：PPIO 推出 Fusion"融合模型"服务形态：通过融合网关整合多个底层模型的能力对外提供统一推理服务，官方宣称在 DRACO 基准上取得 57.34 分、超过 Claude Fable 5 的 55.14，而成本约为后者的十分之一。
  - 技术原理（推理服务层模型融合/路由）：与单模型 API 不同，融合网关在请求层对多个模型输出做组合/路由，以服务侧工程换取效果-成本比；具体融合策略与 DRACO 评测口径见官方博客（基准数字为厂商自述，尚待第三方复现）。属推理服务层的商业模式创新与技术混合体，故附注商业背景、以技术部分收录。
  - 链接：[PPIO 官方博客](https://blog.ppio.com)

## 三、评估与可信层

- **GPT-5"论文正确性检查器"倒查 2500 篇顶会论文：99.2% 被标出至少一处客观错误（论文 2025-12 发布，8/9-10 中文传播高峰）**
  - 简介：斯坦福 James Zou 团队（Together AI / NEC Labs / Rutgers 合作）基于 GPT-5 构建 Paper Correctness Checker，对 ICLR（2018–2025）、NeurIPS（2021–2025）、TMLR（2022–2025）随机抽样的 2500 篇已发表论文做客观错误审计：平均每个论文 4.7 处，99.2% 至少被标出 1 处。该工作论文本体 2025 年 12 月已上 arXiv，8 月 9-10 日随量子位、36Kr、Nature 新闻等集中报道而大范围出圈（含"AI 倒查百年论文"的讹传澄清：99.2% 针对的是这 2500 篇 AI 论文，"百年"另指 AI 复核上世纪化学数据的案例）。
  - 技术原理（LLM 流水线审计 + 人工验证）：只查"客观错误"（公式、推导、计算、图表、交叉引用），不评新颖性/写作。流水线为 GPT-5 双模型结构：一个检测器找错、一个复核器去假阳性并标记"实质性错误"（可能改变结果解读的），GPT-5-mini 做错误分类，最后由 GPT-5 给出修正建议。人工专家核验 316 处疑似错误，263 处属实（精确率 83.2%，召回约 60%）；54% 的错误是数学错误；错误率逐年上升——NeurIPS 从 2021 年 3.8 处/篇涨到 2025 年 5.9 处（+55.3%）；对 75.8% 的错误能给出正确修复。同期发酵的还有 ICML 2026 复现审计（7 月 22 日启动，168 篇 oral 中 92 篇有 ≥5 条可验证结论性陈述，仅 34 篇超 40% 结论被 AI 智能体成功复现）与 HuggingFace × AlphaXiv 的 Agent Reproduction Challenge。
  - 链接：[arXiv:2512.05925（一手论文）](https://arxiv.org/abs/2512.05925) ｜ [Nature 新闻报道](https://www.nature.com/articles/d41586-026-02235-8)（补充） ｜ [量子位/36Kr 中文报道](https://eu.36kr.com/en/p/3931963588836487)（中文补充）

- **WeClawArena：首个"跨用户智能体协作 + 安全"可审计沙箱基准（arXiv 8/4 提交，CMU/USC/ASU）**
  - 简介：针对"每个用户一个个人智能体、彼此跨工作空间协作"的人类中心化智能体网络，CMU/USC/ASU 推出 WeClawArena：124 个基础任务扩展为 620 个场景变体（每任务 1 个良性对照 + 4 个攻击向量变体），覆盖议价、投标、旅行、SWE-Workspace、临床、交易六大跨用户领域，效用与攻击成功率（ASR）分开报告。
  - 技术原理（Docker 化个人工作空间 + 消息网关审计）：每个用户节点实例化为 Docker 容器内的个人工作空间（文件系统、数据库、工具、个人策略），沙箱提供统一消息网关路由多智能体通信、工具调用与资源访问，全程记录 peer 消息、工具调用、资源操作、治理决策与最终工作空间状态；攻击审计基于有限运行时证据，可诊断任务崩坏、隐私泄露、投毒证据、越权路径四类危害。基准直接以 OpenClaw 等持久个人智能体框架为部署假设，是"多用户智能体网络"安全评估的第一块基建。
  - 链接：[arXiv:2608.03499](https://arxiv.org/abs/2608.03499) ｜ [GitHub · WeClawArena](https://github.com/kingofspace0wzz/WeClawArena) ｜ [HuggingFace 数据集](https://huggingface.co/datasets/kingofspace0wzz/WeClawArena)

## 四、编程智能体 / Skill 范式

- **SkillSentry：自适应"蜜罐世界"动态扫描 Agent Skill 安全（arXiv 8/4 提交，8/10 进入 arXiv 新榜）**
  - 简介：外部 skill 扩展 LLM 智能体能力的同时也引入执行期攻击面——静态扫描看不出"条件触发的恶意分支"。SkillSentry 用自适应蜜罐世界做部署前动态安全测试：标准基准 Recall 99.50%、平均 F1 96.26%；面对保语义对抗改写，F1 92.95%（最强基线仅 80.07%）。
  - 技术原理（能力漂移检测 + 成对轨迹对比）：四阶段受控审计：① 从 skill 描述/部署策略推断"能力契约"；② 构造 LLM 模拟环境并布置受控诱饵资源（蜜罐世界），自适应生成任务诱发潜在触发条件；③ 同一初始状态下分别执行"带 skill / 不带 skill"成对运行，排除任务本身与基座智能体的干扰；④ 仅当剩余差异是"已完成的、有源码支撑的、超出宣称功能"的效果才判定违规。同批 arXiv 还有姊妹方向工作 SkillJack（arXiv:2608.03509，自进化智能体中的持久 skill 后门），Skill 供应链攻防正形成完整研究面。
  - 链接：[arXiv:2608.03485](https://arxiv.org/abs/2608.03485) ｜ [GitHub · SkillSentry](https://github.com/nizhangli062-jpg/SkillSentry-Adaptive-Honey-Worlds-for-Dynamic-Safety-Testing-of-Agent-Skills)

- **编程智能体恶意 Skill 风险实测：Gemini CLI 被利用率高达 96%（arXiv 8 月上旬提交）**
  - 简介：Monash 等团队（Rui Yang 等）对"skill 文件夹作为编程智能体动态加载接口"的攻击面做大规模实测：用 6 个 LLM、4 个模型家族把 471 条真实 shell 命令对抗合成为 2826 个"看起来无害"的恶意 skill，映射到 11 类 MITRE ATT&CK 战术；在 5629 次完整运行中，Gemini CLI 被利用率 95.5%–96.1%，Qwen Code 71.6%–74.0%，且与生成恶意 skill 的模型几乎无关。
  - 技术原理（对抗 skill 合成 + 三裁判评估流水线）：评估侧用"运行分层 + 证据锚定 + 拒答否决 + 声明意图确定性覆盖"的三裁判 LLM-as-judge 流水线，并与盲测人工金标准对齐（Cohen's kappa = 0.85）。最刺眼的发现：运行中"明确识别出安全问题"的比例仅 1.99%——企业级编程智能体对 skill 接口的安全审查几乎缺位。
  - 链接：[arXiv:2608.05223](https://arxiv.org/abs/2608.05223) ｜ [GitHub · AgentJailbreak](https://github.com/awsm-research/AgentJailbreak)

- **ARA（Agent-Native Research Artifacts）："最后一篇人类写的论文"引发科研范式讨论（IEEE Spectrum 8/10 报道）**
  - 简介：以 paperbench 为载体、提出"智能体原生科研产物"（Agent-Native Research Artifacts）方向的 ARA 工作持续发酵，IEEE Spectrum 8 月 10 日予以报道；其核心命题被概括为"The Last Human-Written Paper"——科研交付物从"人写的论文"转向"智能体可执行、可验证的产物"。
  - 技术原理（科研产物形态重构 + 基准化评估）：把科研产出重新定义为 agent-native 的可验证工件，并以 paperbench 类基准评估智能体生成/验证这类产物的能力（具体形式与评测口径以仓库为准）。
  - 链接：[GitHub · ARA paperbench](https://github.com/AmberLJC/ara-paperbench) ｜ [IEEE Spectrum 报道](https://spectrum.ieee.org)（补充）

## 五、论文速递

- **LLaDA MoE v2：MoE 扩散语言模型的 scaling laws 与 30B-A3B 实证（arXiv 8/4 提交，人大高瓴 + 蚂蚁）**
  - 简介：扩散语言模型（dLLM）阵营首份系统的 MoE scaling 研究：先系统刻画优化超参、算力分配、MoE 架构三条 scaling 规律，再据此从零训练 LLaDA MoE v2（30B 总参/3B 激活，23.5T tokens）——仅用 Qwen3 约 65% 的预训练 token，在多项知识/推理/编码基准逼近 Qwen3；SFT 后在 8 项推理与编码基准中的 7 项超过 SDAR Chat。
  - 技术原理（MoE dLLM scaling laws）：与自回归模型的差异点：最优 batch size 随算力增长更快、最优学习率衰减更快；IsoFLOP 分析显示算力分配略偏向数据侧（token 预算增长快于激活计算）；规模越大越倾向"更大专家池 + 固定激活容量"，中等专家粒度始终稳健，共享专家占比的最优值跨规模稳定。dLLM 的 masked-denoising 目标使 AR 经验可作先验但需专门校准——这是"非自回归路线能否 scale"的关键实证。
  - 链接：[arXiv:2608.03457](https://arxiv.org/abs/2608.03457)

- **LeanMem：按信息类型分仓的轻量长期记忆，成本与精度双赢（arXiv 8/4 提交，合肥工业大学）**
  - 简介：现有智能体记忆系统用统一摘要流水线处理异构对话，要么 token 消耗过高、要么不可逆丢失细节。LeanMem 按"可压缩性/时间动态/保真要求"把记忆分为画像（profile）/事件（event）/记录（record）三仓，在 LoCoMo 与 LongMemEval-S 上全面超过最强记忆基线（最高 +15.1 分），同时构建/推理 token 与延迟均为最低或近最低。
  - 技术原理（受控写入 + 选择性演化 + 自适应证据组合）：写入端先过滤低价值轮次、主题分段，再由调度器为每段选 ignore/profile/event/record 之一；维护端只演化会随时间变化的事件记忆（缓冲 + 局部延迟整合）；查询端由 LLM 规划器分析证据需求，为不同记忆类型分配不同检索深度并按证据角色组装上下文。对比 A-Mem：精度最高 +20.4 分，构建 token 最多省 17.24 倍、推理 token 省 8.41 倍。
  - 链接：[arXiv:2608.03463](https://arxiv.org/abs/2608.03463)

- **DataSpace：数据智能体的异构工作空间基准，KDD Cup 2026 官方赛题（arXiv 8/4 提交，HKUST(GZ) + 清华）**
  - 简介：智能体要回答的组织数据分析问题，证据往往散落在数据库、结构化文件、长文档与多媒体之间。DataSpace 提供 410 个跨语言任务、7439 个 artifacts（15.01GB，覆盖 CSV/JSON/SQLite/Markdown/PDF/视频），要求智能体只凭问题与工作空间返回完整可验证的表格结果；已作为 KDD Cup 2026"复杂数据分析数据智能体"竞赛官方基准。
  - 技术原理（执行锚定构建 + 确定性评估）：DataSpace-Builder 把英文 Text-to-SQL 资源（EHRSQL/BULL）经跨语言转换、约束感知关系采样、模态路由渲染、11 位领域专家复核修复，转成异构工作空间任务，答案由执行导出；评估器做表头不变列对齐、类型/精度感知归一化与顺序敏感行比较，全程无 LLM 裁判。实测六个前沿多模态模型 + 五种智能体 harness：最好仅 66.34%，固定底座下 harness 选择造成 15.36 分差距，多模态证据整合与 join 一致性地拉低所有底座的表现——基准远未饱和。
  - 链接：[arXiv:2608.03451](https://arxiv.org/abs/2608.03451) ｜ [GitHub · DataSpace](https://github.com/HKUSTDial/DataSpace) ｜ [HuggingFace 数据集](https://huggingface.co/datasets/HKUSTDial/DataSpace)

- **受控世界模型的可辨识性：理论层面回应"世界模型到底学到了什么"（arXiv 7/24 提交，清华 iDLab + 滴滴 Voyager Lab，8/10 中文解读走热）**
  - 简介：世界模型（含 JEPA 类表征学习路线）训练时大量依赖干预/控制信号，但其内部表征能否唯一恢复数据的真实生成因子一直缺乏理论刻画。本文系统研究"受控世界模型"的可辨识性问题，8 月 10 日中文圈解读集中走热。
  - 技术原理（非线性 ICA / 可辨识性理论）：以可辨识性分析框架刻画在何种条件下，从受控/干预数据训练出的世界模型能恢复出本质唯一的潜变量结构，而非一族不可区分的等价解（具体定理与假设以论文为准）。对"世界模型学到的是真实因果结构还是快捷方式"的长期争论给出理论工具。
  - 链接：[arXiv:2607.22430](https://arxiv.org/abs/2607.22430)
