## 一、模型与架构

- **Daedalus-150M：为 CPU 推理反推设计的卷积-注意力混合小模型** 「HF Daily Papers 8-24 上榜」
  - 简介：个人研究者 Christos Koutsiaris 发布的 150M 小模型（arXiv 8-20 提交），与"先做大再压小"相反，先锁定场景（单用户、4-bit、纯 CPU 逐 token 推理）再反推架构，五任务基准 47.31，击败训练数据多 3–6 倍的 GPT-2 124M / Pythia-160M 等。
  - 技术原理（架构创新）：18 个块中仅 6 块保留全注意力，其余 12 块用记忆窗口仅 2 个时间步的短卷积，使网络三分之二不随对话增长重读 KV cache；从零在 59.9B token 上训练。
  - 链接：[论文](https://arxiv.org/abs/2608.20210)

- **ParaTempo：用「时间置信度」提前终止分支的免训练并行推理框架** 「HF Daily Papers 8-24 上榜」
  - 简介：Xuteng Zhang 等提出（arXiv 8-17 提交），对多分支并行采样的推理模型做分支级动态算力控制，降低成本。
  - 技术原理（推理/测试时计算）：定义"时间置信度"——分支局部答案空间收敛度；周期性探测各分支暂定答案分布，一旦某分支近期探测集中于主导答案，即提前终止其余分支。
  - 链接：[论文](https://arxiv.org/abs/2608.16425)

- **SparsePR：面向视频生成与世界模型的免训练块稀疏注意力** 「HF Daily Papers 8-24 上榜」
  - 简介：Pardis Taghavi 等提出（arXiv 8-19 提交），加速 video transformer 的注意力计算。
  - 技术原理（注意力优化）：用 Response-Coupled Partitioning 将采样 query 的 key 响应聚成 K/V 组做共享路由，再用少量精确 query 行在探针残差子空间内拟合仿射校正，重建被稀疏化丢掉的残差输出。
  - 链接：[论文](https://arxiv.org/abs/2608.18484)

- **RARE：MoE 表示工程中解耦行为干预与专家路由**
  - 简介：Zhibo Zhang 等（arXiv 8-21 周五提交，周一公布批次），研究如何对 MoE 模型做行为 steering 而不破坏专家路由。
  - 技术原理（MoE/表示工程）：发现直接干预 MoE 隐状态会扰动路由造成结构性失配；RARE 将行为扰动投影到路由矩阵的零空间，去除路由可见分量并校正路由漂移，实现"路由无关"的行为控制。
  - 链接：[论文](https://arxiv.org/abs/2608.21236)

## 二、多模态模型与应用

- **ElevenLabs CLI v1：面向 Agent 的语音 AI 命令行工具**
  - 简介：ElevenLabs 于 8-24 官方发布，把整套语音 API（语音生成、转写、语音代理）搬进终端，定位"agents as code"，主打 agent-first 开发工作流。
  - 技术原理（语音 + agent 工具链）：语音代理配置作为本地文件管理，支持 dev/prod 分支隔离；每条命令输出机器可读的 typed 契约，错误以可解析 JSON 返回；内置 Skills 教 coding agent 完成"构建语音代理、生成语音、转写通话"等完整工作流。
  - 链接：[官方博客](https://elevenlabs.io/blog/elevenlabs-cli-v1)

- **InfinityEdit：轻量编辑适配器实现「无限长视频编辑」** 「HF Daily Papers 8-24 当日点赞最高」
  - 简介：学术团队提出"无限视频编辑"新设定（arXiv 8-21 提交，周一公布），处理直播换风格、对进行中镜头加运镜等开放流式场景。
  - 技术原理（视频生成）：打破"原地编辑"假设，把编辑定义为"在延续视频流的同时施加编辑"；设计配套数据采集管线，用轻量 edit adapter 让流式视频生成器在无界编辑指令序列下保持稳定质量。
  - 链接：[论文](https://arxiv.org/abs/2608.20910) ｜ [HF 页面](https://huggingface.co/papers/2608.20910)

- **OmniAssistBench：全模态模型「实时视频助手」交互式评测基准** 「HF Daily Papers 8-24 上榜」
  - 简介：面向 Omni-LLM 作为实时视频助手（持续感知环境 + 指导用户完成目标）的交互式基准（arXiv 8-21 提交），构建耗费 1000+ 专家人时。
  - 技术原理（多模态评测）：针对"模型回应会动态改变用户后续行为、静态数据集无法评测"的问题，从源视频反推用户目标、切成多轮片段模拟连续交互，并用源视频派生的先验约束模型按同一路径引导用户，解决交互路径发散。
  - 链接：[论文](https://arxiv.org/abs/2608.21360) ｜ [HF 页面](https://huggingface.co/papers/2608.21360)

## 三、训练与数据

- **Let's Scale Step by Step：大规模 MoE 预训练的超参数迁移框架** 「HF Daily Papers 8-24 上榜」
  - 简介：Nayeon Kim 等提出（arXiv 8-20 提交），解决"万亿 token 规模下学习率扫描成本不可承受"的问题。
  - 技术原理（预训练/μP）：先为 MoE 构造 Maximal Update Parameterization 适配（覆盖 Multi-head Latent Attention 与 Muon 优化器），证明最优学习率可沿模型宽度一致迁移；再沿 token 维度外推到万亿 token 地平线，用小模型低成本确定大模型超参。
  - 链接：[论文](https://arxiv.org/abs/2608.20061)

- **Every Coin Has Two Sides：大模型在策略蒸馏（OPD）泛化行为研究** 「HF Daily Papers 8-24 上榜」
  - 简介：Zhaoyi Li 等的受控研究（arXiv 8-17 提交），系统评估 OPD 的泛化边界。
  - 技术原理（蒸馏/后训练）：每次只变动一个泛化因子（域内偏移、跨域迁移、多教师）；发现 OPD 迁移的是教师的"推理行为"而非具体答案——连教师自己都解不出的难题也能提供学习信号；迁移效果强烈依赖师生同源关系，跨源对大多只拟合训练域。
  - 链接：[论文](https://arxiv.org/abs/2608.16647)

- **Llama-Mobile：2.7-bit 量化的移动端 VLM** 「HF Daily Papers 8-24 上榜」
  - 简介：Luka Ribar 等提出（arXiv 8-21 提交），把 Llama 3.2 11B Vision Instruct 压缩至 3.7 GB 在 Arm CPU 上运行。
  - 技术原理（量化/端侧）：用模型自身生成量化校准数据（不接触原始训练流程），提出 2.7 bit/参数的新数值格式以适配 Arm CPU 执行，8-bit 激活，视觉问答性能保持较强。
  - 链接：[论文](https://arxiv.org/abs/2608.21134)

- **COEC：免训练结构化剪枝的正交补偿方法**
  - 简介：Peiqi Yu 等提出（arXiv 8-21 提交），无需再训练即可恢复剪枝后精度。
  - 技术原理（剪枝）：对保留权重施加左右交替正交旋转，右旋转在缩减 Stiefel 流形上优化，奇异值用广义交叉校准正则化强度后重标定，修正现有方法只加偏置或只做输出侧旋转、无法调整输入奇异框架的缺陷。
  - 链接：[论文](https://arxiv.org/abs/2608.21142)
