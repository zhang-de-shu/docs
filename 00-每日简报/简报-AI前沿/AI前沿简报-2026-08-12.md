## 一、模型与架构

- **阿里开源 Qwen3.8-2.4T-A95B：2.4T 参数旗舰 MoE 开放权重**
  - 简介：阿里 Qwen 于 2026-08-12 23:00（UTC+8）开源旗舰 MoE 模型 Qwen3.8-2.4T-A95B 权重，总参 2.4T、每 token 激活 95B，支持可配置推理（reasoning 开关），为当前最大规模开放权重 LLM 之一。
  - 技术原理（MoE + 多步预测）：每层 512 个专家、每 token 路由 10 个 + 1 个共享专家；采用多步 MTP（Multi-Token Prediction）提升推理吞吐；官方配套 NVIDIA GB300 NVL72 部署方案（TensorRT-LLM/Dynamo，可配置推理预算）。
  - 链接：[ModelScope 模型页](https://modelscope.cn/models/Qwen/Qwen3.8-2.4T-A95B) ｜ [Qwen 官方博客](https://qwen.ai/blog?id=qwen3.8) ｜ [NVIDIA 部署博客](https://developer.nvidia.com/blog/serve-qwen3-8-2-4t-a95b-a-2-4t-parameter-model-with-configurable-reasoning-on-nvidia-gb300-nvl72/)

- **NVIDIA Nemotron 3.5 Lightning（30B-A3B）：面向长时程 agent 的开源 MoE，配套 NeMo Switchyard 路由库**
  - 简介：NVIDIA 于 08-11 发布开源 agent 模型 Nemotron 3.5 Lightning（总参 30B / 激活 3B），主打长时运行 agent 的任务执行，可在 RTX 消费级显卡与 DGX Spark 上运行，NVFP4 检查点随模型提供；同步开源模型路由库 NeMo Switchyard。
  - 技术原理（蒸馏 MoE + 投机解码 + harness 化训练）：MoE 架构、从更大教师模型蒸馏而来；配套 DSpark/DFlash 草稿模型做投机解码加速长生成（官方称输出速度约 4 倍）；针对 OpenClaw、Hermes 等 agent harness 的执行轨迹做 harness 化训练优化；官方自报 PinchBench agent 任务提速 30%、准确率 86%。
  - 链接：[NVIDIA 博客](https://blogs.nvidia.com/blog/nemotron-lightning-switchyard-rtx-dgx/) ｜ [开发者博客](https://developer.nvidia.com/blog/nvidia-nemotron-3-5-lightning-delivers-fast-accurate-specialized-task-execution-for-long-running-agents/)

- **蚂蚁 inclusionAI 开源 Ling-3.0-tiny：KDA+MLA 混合线性注意力端侧 MoE**
  - 简介：蚂蚁百灵 inclusionAI 于 08-11 开源 Ling-3.0-tiny（总参 7.9B / 激活 1.3B），同步放出 FP8、INT4 量化版；M4 Pro MacBook 本地 86–90 tokens/s、首 token 延迟低于 100ms，并已适配 NVIDIA DGX Spark。
  - 技术原理（混合线性注意力 + 小激活 MoE）：KDA（Kimi Delta Attention）与 MLA（Multi-head Latent Attention）按 3:1 交替堆叠；128 个路由专家、每 token 激活 8+1（共享）专家；以极小激活参数换取端侧 agent 场景的速度与低延迟（8K 上下文峰值内存 8.34GiB）。媒体称其 Artificial Analysis Agentic Index 超 Gemma-4-31B（榜单结论未亲验）。
  - 链接：[HF 模型页](https://huggingface.co/inclusionAI/Ling-3.0-tiny) ｜ [FP8 版](https://huggingface.co/inclusionAI/Ling-3.0-tiny-fp8) ｜ [INT4 版](https://huggingface.co/inclusionAI/Ling-3.0-tiny-int4)

## 二、多模态模型与应用

- **Stream Forcing：流式视频生成的统一训练轨迹（世界建模路线）**
  - 简介：Yueting Zhu 等提出 Stream Forcing，面向世界建模场景的流式视频生成（在线逐帧续写连续视频流），解决流式视频扩散模型训练-推理不一致问题。
  - 技术原理（视频扩散采样重构）：把视频扩散采样重构为噪声水平上的"帧索引随机过程"，在该过程空间内构造连续训练轨迹，使采样调度在训练中平滑变化，兼顾训练覆盖与训推一致性，提升长程流式生成鲁棒性。
  - 链接：[arXiv 2608.10439](https://arxiv.org/abs/2608.10439)（08-11 提交）

- **SparSTAR：自回归视频生成的免训练稀疏注意力**
  - 简介：InfinityStar 团队发布 SparSTAR，针对时空自回归视频合成（STAR）中后段尺度注意力开销过大的问题，提出免训练的块稀疏注意力方法，可直接套用于现有模型降低推理成本。
  - 技术原理（块稀疏注意力）：在每个高开销尺度上对连续 key 块打分，保留必要条件上下文，仅前向执行选中的稀疏块，并利用片段内跨尺度一致性与跨片段边界的模式持续性来选块。
  - 链接：[arXiv 2608.10519](https://arxiv.org/abs/2608.10519)（08-11 提交）

- **Ex-Omni-2D：带原生视觉形象的全模态对话模型（数字人方向）**
  - 简介：港中文 Tianshu Yu 组等发布 Ex-Omni-2D：给定多模态输入 + 参考形象图 + 参考音色，单模型同时生成文本回复、个性化语音和参考条件视频，实现"可视对话主体"。
  - 技术原理（Visual Thought Plan + 共享声学接口）：先预测结构化视觉思维计划（场景/情绪/运动），再生成回复文本与多码本语音单元；语音单元构成共享的声学-时间接口，一路解码为语音、一路与视频帧在线对齐，实现口型/表情与语音同步。
  - 链接：[arXiv 2608.10720](https://arxiv.org/abs/2608.10720)（08-11 提交）

- **DuplexWorld：全双工语音 Agent 评测基准**
  - 简介：Aryan Vijay Bhosale 等发布 DuplexWorld，面向 speech-to-speech 语音 Agent 的新评测，构造银行等六个日常场景世界，考察语音 Agent 在真实琐碎对话中的任务协助能力，而非仅数据库式工具调用。
  - 技术原理（场景世界评测）：指出现有 S2S 基准以"对数据库的 agentic tool calling 考试"为主、缺乏日常对话多样性；DuplexWorld 以六个高价值场景世界评测任务忠实协助能力与全双工交互质量。
  - 链接：[arXiv 2608.10716](https://arxiv.org/abs/2608.10716)（08-11 提交）

- **GENEA Challenge 2026：大规模语音驱动手势生成评测**
  - 简介：GENEA 系列挑战赛 2026 版论文上线，基于 Seamless Interaction 数据集对语音驱动手势生成做大规模解耦评测，服务数字人/具身交互的手势合成方向。
  - 技术原理（解耦评测协议）：延续"语音输入→上半身手势生成"设定，本届提供更大规模数据与解耦评估协议，横向比较多种方法在自然度、语义对齐、多样性上的表现。
  - 链接：[arXiv 2608.10839](https://arxiv.org/abs/2608.10839)（08-11 提交）

- **论文：Why Does CLAUDE.md Keep Growing?——Agentic Coding 中的"灾难性记忆"**
  - 简介：首个对 CLAUDE.md 类 agent 指令文件无限膨胀现象的系统性实证研究（08-11 提交），直接关系 harness 的上下文工程与状态管理。
  - 技术原理（指令生命周期实证）：追加指令总是廉价的，而删除一条指令需要 O(2^|D|) 的验证成本，导致 "catastrophic remembering"。实证：1,867 个仓库、247,694 条指令生命周期上，agent prompt 平均增长 +226%，每次 commit 净增 +4.9 条指令，指令越老越难删除。
  - 链接：[arXiv 2608.11095](https://arxiv.org/abs/2608.11095)

- **论文：MEGA——基于 Wisdom Graph 的自进化智能体优化基础设施**
  - 简介：08-11 提交。把"优化 agent 系统"本身做成可持续积累知识的基础设施，面向编程智能体的 self-improvement loop。
  - 技术原理（wisdom 资产闭环）：MEGA 每个优化周期产出可复用的 "wisdom" 资产（行为模式聚类 + 经验性 A/B 验证从会话中蒸馏），再对资产做组合式推理指导后续优化，并用运行证据反向修正知识本身。
  - 链接：[arXiv 2608.10504](https://arxiv.org/abs/2608.10504)

- **论文：EvoX Genesis——持久化递归世界实现自主软件演化**
  - 简介：08-11 提交。面向超越单个 agent 寿命的长任务架构：让"软件项目"持久化，局部 agent 可以短命。
  - 技术原理（persistent recursive world）：每个 local world 由已接受版本 + 仓库路径定位，短命 agent 提出局部修改，递归委托在路径间转移工作，只有被接受的后果才推进持久版本历史。实测用 DeepSeek V4 Flash 从零构建出约 25 万行规模的 Rust 版 C 编译器。
  - 链接：[arXiv 2608.10450](https://arxiv.org/abs/2608.10450)

- **论文：ASCon——多智能体系统失败归因的方向感知互惠建模**
  - 简介：08-11 提交。回答 LLM 多智能体系统"谁导致失败、何时、为何"，统一识别故障 agent、错误步骤与失败模式。
  - 技术原理（方向感知互惠建模）：把 MAS 轨迹证据（任务约束、角色、行为历史、agent 间交互）聚合成统一的 agent/step 表示，再适配到不同归因目标，避免为各归因任务单训专用模型。
